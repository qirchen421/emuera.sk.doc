# SKIPLOG

| 函数名                                                     | 参数  | 返回值 |
| :--------------------------------------------------------- | :---- | :----- |
| ![](../assets/images/IconEE.webp)[`SKIPLOG`](./SKIPLOG.md) | `int` | `void` |

!!! info "API"

	``` { #language-erbapi }
	SKIPLOG bool
	```

	用于手动控制通过左键点击等方式跳过日志的状态。非0值启用跳过，0值解除跳过状态。

!!! hint "提示"

    仅可作为指令使用。
