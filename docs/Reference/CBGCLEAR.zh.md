# CBGCLEAR

| 函数名                                                           | 参数 | 返回值 |
| :--------------------------------------------------------------- | :--- | :----- |
| ![](../assets/images/IconEmuera.webp)[`CBGCLEAR`](./CBGCLEAR.zh.md) | 无   | `int`  |

!!! info "API"

    ```  { #language-erbapi }
	int CBGCLEAR
    ```
    解除所有通过以`CBG`开头的各种`CBG`系命令设置的背景图片设定。

!!! hint "提示"

    同时支持命令形式和表达式函数形式。
