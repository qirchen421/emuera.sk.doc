# REDRAW, CURRENTREDRAW

| 関数名                                                              | 引数 | 戻り値 |
| :------------------------------------------------------------------ | :--- | :----- |
| ![](../assets/images/IconEmuera.webp)[`REDRAW`](./REDRAW.md)        | `int`| なし   |
| ![](../assets/images/IconEmuera.webp)[`CURRENTREDRAW`](./REDRAW.md) | なし | `int`  |

!!! info "API"

    ```  { #language-erbapi }
	REDRAW int
	int CUREENTREDRAW
    ```
	描画制御命令です。  
	引数に`0`を指定すると、**強制的でない描画要求を抑止**します（ユーザーが入力を必要とするタイミングなど、強制的な描画の機会にのみ描画されます）。  
	引数に`1`を指定すると通常通り描画を行います。このとき、強制的でない描画は[コンフィグの`フレーム毎秒`](../Emuera/config.md#fps)で決まる最小間隔（`1000 / フレーム毎秒` ミリ秒）に満たない場合は描画されません。  
	引数に`2`を加えると(`REDRAW 2`や`REDRAW 3`など)、上記の効果に加え、`REDRAW`命令を行った瞬間に強制的に描画を行います。  
	現在の`REDRAW`状態（`0`または`1`）は`CURRENTREDRAW`で取得することができます。  

!!! info "詳細"

	`REDRAW`が持つ状態は`0`（抑止）と`1`（通常）の2つだけです。`CURRENTREDRAW`も`0`または`1`を返します。  
	`REDRAW 1`は状態を戻すだけで、**それ自体は描画を行いません**。`REDRAW`命令の直後に必ず描画させたい場合は、`2`を加えた`REDRAW 3`を使ってください。  
	`REDRAW 0`で抑止されるのは強制的でない描画だけです。ユーザーの入力を待つ命令（`INPUT`・`INPUTS`・`INPUTSNF`・`TINPUT`系）に入る時点の描画、およびボタン上へのマウス移動による描画は抑止されません。  

!!! warning "注意（まとめ描画とスクロール位置）"

	「一度消して描き直す」画面（アニメーションループや動的地図など）では、消去から再描画までの間を`REDRAW 0`で囲み、入力待ちに入る前に元へ戻してください。

	```  { #language-erbapi }
	PREV_REDRAW = CURRENTREDRAW()
	REDRAW 0
	;	CLEARLINE と再描画
	REDRAW PREV_REDRAW
	;	この後の入力待ちで強制描画される
	```

	まとめ描画を行わないと、消去済み・再描画未完了の中間状態が実際に描画されます。描画はスクロール位置の同期を伴うため、**画面が最新行に固定されなくなります**（行が消えては戻る、ウィンドウが揺れる、といった見え方になります）。  

	また、`REDRAW 1`を「描画を戻す」ための締めとして使わないでください。呼び出し元の設定を上書きします。復元には保存しておいた値（`REDRAW PREV_REDRAW`）を使ってください。  

!!! hint "ヒント"

    `CURRENTREDRAW`は式中関数対応しています。
