# BREAKBUTTON

| 関数名                                                         | 引数   | 戻り値 |
| :------------------------------------------------------------- | :----- | :----- |
| ![](../assets/images/IconEE.webp)[`BREAKBUTTON`](./BREAKBUTTON.md) | `()`   | 無     |

!!! info "API"

    ``` { #language-erbapi }
	BREAKBUTTON
    ```

	画面のボタン化を強制的に更新します。  
	通常、ボタン化はフレームごとに自動的に行われますが、この命令を使用することで即時にボタン化を更新することができます。  
	特に、動的にテキストを変更した後にボタンを即座に有効にしたい場合に使用します。

!!! hint "ヒント"

	命令なので式中関数としては使用できません。  
	引数はありません。
