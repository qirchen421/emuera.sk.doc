# FORCEKANA

| 関数名                                                             | 引数 | 戻り値 |
| :----------------------------------------------------------------- | :--- | :----- |
| ![](../assets/images/IconEmuera.webp)[`FORCEKANA`](./FORCEKANA.md) | `int`| なし   |

!!! info "API"

    ```  { #language-erbapi }
	FORCEKANA int
    ```
	表示命令のひらがな・カタカナを指定します。
	キーワード`K`を含む各種[`PRINT`](./PRINT.md)系命令で有効になります。
	引数で指定した値により、以下の影響があります。

	- 0:変換を行わない
	- 1:ひらがな→カタカナ
	- 2:カタカナ→ひらがな（全角のみ）
	- 3:カタカナ→ひらがな（全角・半角両方とも）

!!! hint "ヒント"

    命令のみ対応しています。
