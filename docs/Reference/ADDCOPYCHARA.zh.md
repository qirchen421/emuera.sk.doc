# ADDCOPYCHARA

| 函数名                                                                   | 参数 | 返回值 |
| :----------------------------------------------------------------------- | :--- | :----- |
| ![](../assets/images/IconEmuera.webp)[`ADDCOPYCHARA`](./ADDCOPYCHARA.zh.md) | `int`| 无     |

!!! info "API"

    ```  { #language-erbapi }
	ADDCOPYCHARA charaID
    ```
	新增一个与参数指定登记编号 (CharaID) 的角色数据完全相同的角色。也就是说，这是 `ADDCHARA` 的一个变体。

!!! hint "提示"

    仅支持作为指令使用。
