# SKIPLOG

| Function name                                                   | Arguments  | Return |
| :------------------------------------------------------------- | :----------| :------|
| ![](../assets/images/IconEE.webp)[`SKIPLOG`](./SKIPLOG.en.md)   | `int`      | `void` |

!!! info "API"

	``` { #language-erbapi }
	SKIPLOG bool
	```

	Controls the log skip state via left-click etc. Non-zero enables skip, zero disables skip state.

!!! hint "Hint"

    Command only.
