# CONVERT

| 函数名                                                         | 参数         | 返回值   |
| :------------------------------------------------------------- | :----------- | :------- |
| ![](../assets/images/IconEmuera.webp)[`CONVERT`](./CONVERT.zh.md) | `int`, `int` | `string` |

!!! info "API"

    ```  { #language-erbapi }
	
	string CONVERT value, ※
    ```
	※处只能填入2、8、10、16。  
	返回将第一个参数表示为2、8、10或16进制数的字符串。  

!!! hint "提示"

    同时支持指令和表达式函数两种形式。
