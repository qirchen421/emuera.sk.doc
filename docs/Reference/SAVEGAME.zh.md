# SAVEGAME, LOADGAME

| 函数名                                                             | 参数   | 返回值 |
| :----------------------------------------------------------------- | :----- | :----- |
| ![](../assets/images/Iconeramaker.webp)[`SAVEGAME`](./SAVEGAME.zh.md) | 无     | 无     |
| ![](../assets/images/Iconeramaker.webp)[`LOADGAME`](./SAVEGAME.zh.md) | 无     | 无     |

!!! info "API"

    ```  { #language-erbapi }
    SAVEGAME
    LOADGAME
    ```
    `SAVEGAME` 用于呼出存档画面，`LOADGAME` 用于呼出读档画面。两者都只能在 `SHOP` 状态下调用。

!!! hint "提示"

    仅支持作为指令使用。
