# DELDATA

| 函数名                                                         | 参数 | 返回值 |
| :------------------------------------------------------------- | :--- | :----- |
| ![](../assets/images/IconEmuera.webp)[`DELDATA`](./DELDATA.zh.md) | `int`| 无     |

!!! info "API"

    ```  { #language-erbapi }
	DELDATA saveID
    ```
	删除由 `saveID` 指定编号的文件数据。  
	即使文件不存在也不会报错。  

!!! hint "提示"

    仅支持指令形式。
