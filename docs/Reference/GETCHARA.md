# GETCHARA

| 関数名                                                           | 引数  | 戻り値 |
| :--------------------------------------------------------------- | :---- | :----- |
| ![](../assets/images/IconEmuera.webp)[`GETCHARA`](./GETCHARA.md) | `int` | `int`  |

!!! info "API"

    ```  { #language-erbapi }
	int GETCHARA charaNO
    ```
	現在所有しているキャラの中にそのキャラがいるかを判定し、いればリスト上での位置を、いなければ`-1`を返します  
	リスト全体から特定のキャラの有無を確認したい場合に使えます  

!!! hint "ヒント"

    命令、式中関数両方対応しています。
