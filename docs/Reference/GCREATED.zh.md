# GCREATED

| 函数名                                                           | 参数  | 返回值 |
| :--------------------------------------------------------------- | :---- | :----- |
| ![](../assets/images/IconEmuera.webp)[`GCREATED`](./GCREATED.zh.md) | `int` | `int`  |

!!! info "API"

    ```  { #language-erbapi }
	int GCREATED gID
    ```
	如果指定`gID`的`Graphics`已创建则返回1，未创建（包括已销毁）则返回0。

!!! hint "提示"

    同时支持指令和表达式函数两种用法。
