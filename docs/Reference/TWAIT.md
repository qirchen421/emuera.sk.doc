# TWAIT

| 関数名                                                     | 引数         | 戻り値 |
| :--------------------------------------------------------- | :----------- | :----- |
| ![](../assets/images/IconEmuera.webp)[`TWAIT`](./TWAIT.md) | `int`, `int` | なし   |

!!! info "API"

    ```  { #language-erbapi }
	TWAIT timeLimit, forceWait
    ```
	第一引数が制限時間、第二引数が入力受付フラグです。
	制限時間経過するまで動作を停止します
	実際の挙動は入力受付フラグの指定によって変化します

	- 入力受付フラグ = 0：入力を受け付け、入力がなされると制限時間前でも次に進みます
	- 入力受付フラグ != 0：入力を受け付けません（制限時間まで強制的に待たせることができます）

!!! hint "ヒント"

    命令のみ対応しています。
