# STRFORM

| 函数名                                                         | 参数     | 返回值   |
| :------------------------------------------------------------- | :------- | :------- |
| ![](../assets/images/IconEmuera.webp)[`STRFORM`](./STRFORM.zh.md) | `string` | `string` |

!!! info "API"

    ```  { #language-erbapi }
	string STRFORM formedString
    ```
    将给定的字符串视为与PRINTFORM等相同的格式化字符串，并返回展开后的字符串。

!!! hint "提示"

    同时支持指令和表达式函数两种形式。
