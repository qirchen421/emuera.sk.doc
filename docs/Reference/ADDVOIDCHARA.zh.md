# ADDVOIDCHARA

| 函数名                                                                   | 参数 | 返回值 |
| :----------------------------------------------------------------------- | :--- | :----- |
| ![](../assets/images/IconEmuera.webp)[`ADDVOIDCHARA`](./ADDVOIDCHARA.md) | 无   | 无     |

!!! info "API"

    ```  { #language-erbapi }
	ADDVOIDCHARA
    ```
	此指令用于不依赖 CSV 文件添加角色。  
	通过 `ADDVOIDCHARA` 添加的角色，其所有变量均被赋值为 `0` 或空字符串。  

!!! hint "提示"

    仅支持指令形式。
