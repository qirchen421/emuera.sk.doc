# WAITANYKEY

| 函数名                                                               | 参数 | 返回值 |
| :------------------------------------------------------------------- | :--- | :----- |
| ![](../assets/images/IconEmuera.webp)[`WAITANYKEY`](./WAITANYKEY.md) | 无   | 无     |

!!! info "API"

    ```  { #language-erbapi }
	WAITANYKEY
    ```
	等待任意按键输入或鼠标点击的 [`WAIT`](./WAIT.md) 指令。  
	也可以说是 `WAIT` 的 [`ONEINPUT`](./ONEINPUT.md) 版本。

!!! hint "提示"

    仅指令本身同时支持两种输入方式。
