# CBGCLEARBUTTON

| Function name                                                          | Arguments | Return |
| :-------------------------------------------------------------------- | :-------- | :----- |
| ![](../assets/images/IconEmuera.webp)[`CBGCLEARBUTTON`](./CBGCLEARBUTTON.en.md) | none      | `int`  |

!!! info "API"

    ```  { #language-erbapi }
	int CBGCLEARBUTTON
    ```
	Clears the button settings set by the [`CBGSETBUTTONSPRITE`](./CBGSETBUTTONSPRITE.en.md) command.

!!! hint "Hint"

    Both command and expression function supported.
