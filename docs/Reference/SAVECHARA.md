# SAVECHARA

| 関数名                                                             | 引数                                    | 戻り値 |
| :----------------------------------------------------------------- | :-------------------------------------- | :----- |
| ![](../assets/images/IconEmuera.webp)[`SAVECHARA`](./SAVECHARA.md) | `string`, `string`, `int`(, `int`...)   | なし   |

!!! info "API"

    ```  { #language-erbapi }
	SAVECHARA filename, memo, charaNO{,charaNO2...}
    ```
	指定したキャラクタのデータをファイルに保存する命令です。  
	第一引数はデータをセーブするファイル名(の一部)を指定します。実際のファイル名は`chara_*.dat`になります。  
	第二引数はセーブデータのメモとなる文字列を保存します。後に[`CHKCHARADATA`](./CHKCHARADATA.md)関数により読むことができます。  
	第三引数以降にはセーブしたいキャラの登録番号を指定します。いくつでも可能ですが同一の登録番号を複数回指定することはできません。  
	datフォルダーが存在しない場合、フォルダの作成を試みます。作成に失敗した場合エラーになります。  
	また、第一引数が空文字列である、第一引数にファイル名に使えない文字が含まれるなどの場合エラーになります。  

!!! hint "ヒント"

    命令のみ対応しています。
