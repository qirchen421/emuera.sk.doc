# SAVENOS

| 関数名                                                         | 引数 | 戻り値 |
| :------------------------------------------------------------- | :--- | :----- |
| ![](../assets/images/IconEmuera.webp)[`SAVENOS`](./SAVENOS.md) | `int`| `int`  |

!!! info "API"

    ```  { #language-erbapi }
	int SAVENOS variable
    ```
	命令の場合、コンフィグ[`表示するセーブデータ数`](../Emuera/config.md#_10)で指定された数を取得し指定された数値変数に代入します。標準は`20`です。  
	数値変数を省略することはできません。  

	式中関数の場合、コンフィグ`表示するセーブデータ数`で指定された数を返します。標準は20です。  
	`GETCONFIG("表示するセーブデータ数")`と同義です  

!!! hint "ヒント"

    命令、式中関数両方対応しています。
