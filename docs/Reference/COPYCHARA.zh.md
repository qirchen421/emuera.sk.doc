# COPYCHARA

| 函数名                                                             | 参数         | 返回值 |
| :----------------------------------------------------------------- | :----------- | :----- |
| ![](../assets/images/IconEmuera.webp)[`COPYCHARA`](./COPYCHARA.md) | `int`, `int` | 无     |

!!! info "API"

    ```  { #language-erbapi }
	COPYCHARA charaID, charaID
    ```
	将第一个参数指定的注册编号角色的所有数据复制到第二个参数指定的注册编号角色。

!!! hint "提示"

    仅支持指令形式。
