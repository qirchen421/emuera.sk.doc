# ASSERT

| 関数名                                                       | 引数  | 戻り値 |
| :----------------------------------------------------------- | :---- | :----- |
| ![](../assets/images/IconEmuera.webp)[`ASSERT`](./ASSERT.md) | `int` | なし   |

!!! info "API"

    ```  { #language-erbapi }
	ASSERT bool
    ```
	`DEBUG`系命令は[デバッグモード](../Emuera/debug.md)で起動したときのみ動作します。  
	非デバッグモード時には何もしません。  
	非デバッグモード時には引数の解析も行われないため、<書式付文字列>におかしな点ががあってもエラーになりません。  

	`ASSERT`は引数が真(非0)のとき、何もしません。
	引数が偽(0)の時、エラーを出力してスクリプトの実行を停止します。

!!! hint "ヒント"

    命令のみ対応しています。
