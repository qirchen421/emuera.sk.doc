# BARSTR

| 函数名                                                       | 参数                | 返回值  |
| :----------------------------------------------------------- | :------------------ | :------ |
| ![](../assets/images/IconEmuera.webp)[`BARSTR`](./BARSTR.md) | `int`, `int`, `int` | `string`|



!!! info "API"

    ```  { #language-erbapi }
	string BARSTR value, maxValue, length
    ```
	将使用相同参数的[`BAR`](./BAR.md)命令所显示的字符串赋值给RESULTS:0或返回该字符串。

!!! hint "提示"

    该功能同时支持作为命令和表达式函数使用。
