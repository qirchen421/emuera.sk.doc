# SETBGMVOLUME

| Function name                                                           | Arguments | Return |
| :---------------------------------------------------------------------- | :-------- | :----- |
| ![](../assets/images/IconEE.webp)[`SETBGMVOLUME`](./SETBGMVOLUME.md) | `int`     | `void` |

!!! info "API"

	``` { #language-erbapi }
	SETBGMVOLUME int(0 to 100)
	```

	Sets the volume for `PLAYBGM` to a value between 0 and 100

!!! hint "Hint"

    Available as command only
