# MOUSEB

| 函数名                                                   | 参数 | 返回值   |
| :------------------------------------------------------- | :--- | :------- |
| ![](../assets/images/IconEE.webp)[`MOUSEB`](./MOUSEB.md) | 无   | `string` |

!!! info "API"

	``` { #language-erbapi }
	string MOUSEB
	```

	获取鼠标悬停中的按钮内容

!!! hint "提示"

    支持在表达式中使用  
	可与 AWAIT 组合使用  
	由于执行时点无法确定是 `INPUT` 还是 `INPUTS`，因此返回字符串类型
