# BARSTR

| Function name                                                    | Arguments          | Return   |
| :--------------------------------------------------------------- | :----------------- | :--------|
| ![](../assets/images/IconEmuera.webp)[`BARSTR`](./BARSTR.en.md)   | `int`, `int`, `int` | `string`|

!!! info "API"

    ```  { #language-erbapi }
	string BARSTR value, maxValue, length
    ```
	Returns in `RESULTS:0` the same string that would be displayed by the [`BAR`](./BAR.en.md) command with the same arguments.

!!! hint "Hint"

    Command and expression function both supported.
