# PRINTCLENGTH

| 函数名                                                                   | 参数 | 返回值 |
| :----------------------------------------------------------------------- | :--- | :----- |
| ![](../assets/images/IconEmuera.webp)[`PRINTCLENGTH`](./PRINTCLENGTH.zh.md) | 无   | `int`  |

!!! info "API"

    ```  { #language-erbapi }
	int PRINTCLENGTH
    ```
	返回配置项[`PRINTC的字符数`](../Emuera/config.md#printc_1)的值。与 RESULT = GETCONFIG("PRINTC的字符数") 同义。  

!!! hint "提示"

    同时支持指令和表达式函数。
