# ISACTIVE

| 関数名                                                           | 引数 | 戻り値 |
| :--------------------------------------------------------------- | :--- | :----- |
| ![](../assets/images/IconEmuera.webp)[`ISACTIVE`](./ISACTIVE.md) | none | `int`  |

!!! info "API"

    ```  { #language-erbapi }
	ISACTIVE
    ```
	Returns the state of Emuera's window.  
	Returns 1 if active, 0 if not active.

!!! hint "Hint"

    Both commands and expression functions are supported.
