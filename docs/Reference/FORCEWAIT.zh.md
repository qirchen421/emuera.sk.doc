# FORCEWAIT

| 函数名                                                             | 参数 | 返回值 |
| :----------------------------------------------------------------- | :--- | :----- |
| ![](../assets/images/IconEmuera.webp)[`FORCEWAIT`](./FORCEWAIT.zh.md) | 无   | 无     |

!!! info "API"

    ```  { #language-erbapi }
	FORCEWAIT
    ```
	这是一个无法通过右键点击或宏跳过功能跳过的 [`WAIT`](./WAIT.zh.md) 指令。
	当执行到此指令时，这些跳过状态将被解除。

!!! hint "提示"

    仅支持指令形式。
