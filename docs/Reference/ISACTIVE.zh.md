# ISACTIVE

| 函数名                                                           | 参数 | 返回值 |
| :--------------------------------------------------------------- | :--- | :----- |
| ![](../assets/images/IconEmuera.webp)[`ISACTIVE`](./ISACTIVE.md) | 无   | `int`  |

!!! info "API"

    ```  { #language-erbapi }
	ISACTIVE
    ```
	返回 Emuera 窗口的状态。  
	如果窗口处于活动状态则返回 1，否则返回 0。

!!! hint "提示"

    该函数既可作为指令使用，也可在表达式中使用。
