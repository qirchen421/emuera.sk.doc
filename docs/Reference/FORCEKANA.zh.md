# FORCEKANA

| 函数名                                                             | 参数 | 返回值 |
| :----------------------------------------------------------------- | :--- | :----- |
| ![](../assets/images/IconEmuera.webp)[`FORCEKANA`](./FORCEKANA.md) | `int`| 无     |

!!! info "API "

    ```  { #language-erbapi }
	FORCEKANA int
    ```
	指定显示命令的平假名/片假名转换。
	对包含关键字`K`的各种[`PRINT`](./PRINT.md)系命令有效。
	根据参数指定的值，会产生以下影响。

    - 0:不进行转换
    - 1:平假名→片假名
    - 2:片假名→平假名（仅全角）
    - 3:片假名→平假名（全角、半角均转换）

!!! hint "提示"

    仅支持命令。
