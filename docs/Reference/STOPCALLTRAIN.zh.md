# STOPCALLTRAIN

| 函数名                                                                     | 参数 | 返回值 |
| :------------------------------------------------------------------------- | :--- | :----- |
| ![](../assets/images/IconEmuera.webp)[`STOPCALLTRAIN`](./STOPCALLTRAIN.md) | 无   | 无     |

!!! info "API"

    ```  { #language-erbapi }
	STOPCALLTRAIN
    ```
	如果在 [`CALLTRAIN`](./CALLTRAIN.md) 指令正在运行时被调用，则会立即终止 CALLTRAIN 的处理。  
	其他情况下不执行任何操作。  

!!! hint "提示"

    仅支持命令形式。
