# SQRT

| 函数名                                                   | 参数  | 返回值 |
| :------------------------------------------------------- | :---- | :----- |
| ![](../assets/images/IconEmuera.webp)[`SQRT`](./SQRT.md) | `int` | `int`  |

!!! info "API"

    ```  { #language-erbapi }
	int SQRT int
    ```
    返回参数的平方根。由于小数部分会被舍去，建议在使用前先将数值放大。

!!! hint "提示"

    该函数同时支持指令和表达式函数两种用法。
