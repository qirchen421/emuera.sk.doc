# SPRITECREATED

| 函数名                                                                     | 参数     | 返回值 |
| :------------------------------------------------------------------------- | :------- | :----- |
| ![](../assets/images/IconEmuera.webp)[`SPRITECREATED`](./SPRITECREATED.md) | `string` | `int`  |

!!! info "API"

    ```  { #language-erbapi }
	int SPRITECREATED spriteName
    ```
    若指定名称的精灵已创建则返回1，若未创建或已销毁则返回0。

!!! hint "提示"

    该函数同时支持在指令和表达式中使用。
