# SAVEGAME, LOADGAME

| Function name                                                       | Arguments | Return |
| :----------------------------------------------------------------- | :-------- | :----- |
| ![](../assets/images/Iconeramaker.webp)[`SAVEGAME`](./SAVEGAME.en.md) | none  | none   |
| ![](../assets/images/Iconeramaker.webp)[`LOADGAME`](./SAVEGAME.en.md) | none  | none   |

!!! info "API"

    ```  { #language-erbapi }
	SAVEGAME
	LOADGAME
    ```
	`SAVEGAME` calls the save screen, and `LOADGAME` calls the load screen. Neither can be called outside of `SHOP`.

!!! hint "Hint"

    Commands only.
