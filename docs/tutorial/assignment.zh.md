## 概述

赋值语句是 ERABASIC 中最基本的操作之一——将值存入变量。虽然语法看起来简单，但 ERABASIC 的赋值有几种不同形式，每种适用于不同的场景：

| 赋值形式 | 语法 | 适用类型 | 说明 |
|---------|------|---------|------|
| 基本赋值 | `X = 10` | 整数/浮点 | 最常用的形式 |
| 字符串 FORM 赋值 | `S = Hello %NAME%` | 字符串 | 支持 `%变量%` 字符串替换、`{变量}` 数值插值 |
| 字符串表达式赋值 | `S '= "Hello"` | 字符串 | 用表达式求值，不插值 |
| 复合赋值 | `X += 5` | 整数/浮点/字符串 | 算术运算 + 赋值 |
| 自增/自减 | `X ++` / `X --` | 整数/浮点 | 前置或后置 |
| 批量赋值 | `A:10 = 1,2,3` | 数组 | 连续元素赋值 |

!!! note "eramaker 兼容性"
    基本赋值（`=`）、复合赋值（`+=`/`-=`/`*=`/`/=`/`%=`）、字符串 FORM 赋值是 eramaker 就存在的功能。自增/自减（`++`/`--`）、字符串表达式赋值（`'=`）、批量赋值是 Emuera 的扩展功能。

---

## 解析器如何识别赋值语句

ERABASIC 的解析器在遇到一行代码时，按以下顺序判断：

```
1. 行首是 ++ 或 -- ？ → 前置自增/自减语句
2. 行首是已知命令名？ → 命令语句（如 PRINT、CALL 等）
3. 以上都不是 → 尝试解析为赋值语句
```

当解析器判断一行不是命令时，它会：

1. 用 `LexicalAnalyzer.Analyse` 读取赋值目标（等号左侧的变量）
2. 用 `LexicalAnalyzer.ReadAssignmentOperator` 读取赋值运算符
3. 将剩余部分作为表达式解析（等号右侧）

这意味着**赋值语句的左侧必须是变量**，不能是表达式或常量。

## 基本赋值

### 整数赋值

```erb
A = 100
MONEY = 500
FLAG:0 = 1
ABL:TARGET:0 = 3
```

等号右侧可以是任意整数表达式：

```erb
A = 10 + 20
A = B * 2 + C
A = MAX(10, 20)
A = STRLEN("hello")
```

### 浮点赋值

```erb
#DIMF SCORE
SCORE = 3.14
SCORE = 10 / 3.0
```

!!! warning "整数除法 vs 浮点除法"

    `10 / 3` 的结果是 `3`（整数除法，截断小数），而 `10 / 3.0` 的结果是 `3.333...`（浮点除法）。
    赋值目标变量的类型不影响右侧表达式的计算方式。

## 字符串赋值

字符串变量有两种赋值方式，行为完全不同：

### FORM 语法赋值（`=`）

使用 `=` 赋值时，右侧按 FORM 语法解析——`{变量}` 会被插值，`%变量%` 也会被替换：

```erb
NAME:0 = 艾莉娜
STR:0 = 你好，%NAME:0%！        ; → "你好，艾莉娜！"
STR:1 = 金钱：{MONEY}元          ; → "金钱：500元"
STR:2 = %NAME:0%的冒险           ; → "艾莉娜的冒险"
STR:3 = NAME:0                   ; → "NAME:0"（不加 % 就是字面量！）
STR:4 = CSVNAME(0)               ; → "CSVNAME(0)"（函数不会被调用，原样字面量）
```

这是 eramaker 的原始行为。在 eramaker 中，`STR:0 = %RESULTS%` 会将 `RESULTS` 的内容赋给 `STR:0`。

### 字符串表达式赋值（`'=`）

使用 `'= ` 赋值时，右侧按**字符串表达式**解析——不做 FORM 插值，而是用表达式求值：

```erb
STR:0 '= "你好"                  ; → "你好"（字面量）
STR:1 '= "Hello %NAME:0%"        ; → "Hello %NAME:0%"（不插值！百分号是字面文本）
STR:2 '= NAME:0 + "的冒险"       ; → "艾莉娜的冒险"（字符串拼接）
STR:3 '= TSTR:0 + "继续"         ; → 变量值 + "继续"
STR:4 '= CSVNAME(0)              ; → 角色0的姓名（表达式求值才会调用函数）
```

### 两种方式对比

| | `=` (FORM 语法) | `'= ` (表达式) |
|------|:---:|:---:|
| `{变量}` 插值 | ✅ | ❌ |
| `%变量%` 替换 | ✅ | ❌ |
| 字符串拼接 `+` | ❌ | ✅ |
| 字符串字面量 `""` | 不需要 | **必须** |
| 表达式函数调用 | ❌ | ✅ |
| eramaker 兼容 | ✅ | ❌（Emuera 新增） |

!!! tip "选择建议"

    - 需要简单的变量插值 → 用 `=`（FORM 语法更简洁）
    - 需要字符串拼接、函数调用、复杂表达式 → 用 `'= `
    - 不确定时，用 `'= ` + `""` 包裹字符串更安全（不会意外插值）

## 复合赋值

复合赋值运算符将算术运算和赋值合并为一步：

```erb
X += 5          ; X = X + 5
X -= 3          ; X = X - 3
X *= 2          ; X = X * 2
X /= 4          ; X = X / 4
X %= 10         ; X = X % 10（取余）
```

Emuera 还支持位运算复合赋值：

```erb
X <<= 2         ; X = X << 2（左移）
X >>= 1         ; X = X >> 1（右移）
X |= 0xFF       ; X = X | 0xFF（按位或）
X &= 0x0F       ; X = X & 0x0F（按位与）
X ^= 0xAA       ; X = X ^ 0xAA（按位异或）
```

字符串变量也支持 `+=`：

```erb
STR:0 += "追加文本"     ; 字符串拼接（Emuera 扩展）
```

!!! warning "复合赋值不能用于批量赋值"

    ```erb
    ; ❌ 错误：复合赋值不支持批量赋值
    A:10 += 1,2,3

    ; ✅ 正确：使用基本赋值的批量形式
    A:10 = 1,2,3
    ```

## 自增与自减

### 后置形式（语句行）

```erb
X ++            ; X = X + 1
X --            ; X = X - 1
```

后置自增/自减作为**独立语句**使用，不能嵌入表达式中：

```erb
; ✅ 正确：独立语句
X ++

; ❌ 错误：不能嵌入表达式
A = X ++ + 1
```

### 前置形式（语句行）

```erb
++X             ; 前置自增（作为独立语句）
--X             ; 前置自减（作为独立语句）
```

前置自增/自减也是独立语句。解析器在行首检测到 `++` 或 `--` 时，会将其识别为前置自增/自减语句。

!!! warning "前置自增/自减的严格规则"

    行首的 `++` 或 `--` 必须紧跟一个变量名。如果 `++` 或 `--` 后面不是变量，会报错：

    ```erb
    ; ❌ 错误：++ 后面不是变量
    ++ 5
    ++ (A + B)

    ; ✅ 正确
    ++ A
    ++ FLAG:0
    ```

### 表达式中的自增/自减

在表达式内部（如赋值右侧、IF 条件等），可以使用后置 `++`/`--`：

```erb
A = X ++        ; A = X 的当前值，然后 X = X + 1
IF Y -- > 0     ; 判断 Y > 0，然后 Y = Y - 1
```

但**不能**在表达式中使用前置 `++`/`--`：

```erb
; ❌ 错误：表达式中不能使用前置自增
A = ++ X
```

## 批量赋值

对数组变量赋值时，可以用逗号分隔多个值，实现连续元素的批量赋值：

```erb
; 将 A:10、A:11、A:12 分别赋值为 1、2、3
A:10 = 1,2,3

; 二维数组：将 DA:0:0、DA:0:1、DA:0:2 分别赋值
DA:0:0 = 1,2,3
```

!!! warning "批量赋值的限制"

    1. **不跨行赋值**：二维数组批量赋值不会自动换行。`DA:0:0 = 1,2,3` 只赋值 `DA:0:0`~`DA:0:2`，不会继续到 `DA:1:0`
    2. **不支持复合赋值**：不能写 `A:10 += 1,2,3`
    3. **字符串批量赋值必须用 `'= `**：

    ```erb
    ; ❌ 错误：用 = 会将整个内容当作一个 FORM 字符串
    STR:20 = 草莓,蜜瓜,蓝色夏威夷
    ; → STR:20 = "草莓,蜜瓜,蓝色夏威夷"（一个字符串）

    ; ✅ 正确：用 '= 分别赋值
    STR:20 '= "草莓", "蜜瓜", "蓝色夏威夷"
    ; → STR:20 = "草莓", STR:21 = "蜜瓜", STR:22 = "蓝色夏威夷"
    ```

## `==` 作为赋值运算符

ERABASIC 有一个历史遗留行为：`==`（通常是比较运算符）出现在赋值位置时，会被当作赋值运算符 `=` 处理：

```erb
A == 10         ; 等同于 A = 10（会发出警告）
```

解析器检测到 `==` 在赋值位置时，会发出警告但仍然执行赋值。这是因为早期代码中经常误用 `==` 作为赋值，为了兼容性而保留此行为。

!!! danger "不要在新代码中使用 == 赋值"

    虽然引擎会容忍 `==` 赋值，但这会降低代码可读性并产生警告。始终使用 `=` 进行赋值，`==` 仅用于比较。

## 赋值与类型系统

ERABASIC 有三种基本类型：整数（Int64）、字符串（String）、浮点（Double）。赋值时类型必须匹配：

| 目标变量类型 | 允许的赋值 | 不允许的赋值 |
|------------|----------|------------|
| 整数 (`#DIM`) | 整数表达式 | 字符串、浮点（截断为整数） |
| 字符串 (`#DIMS`) | `=` FORM 语法 或 `'= ` 字符串表达式 | 整数表达式 |
| 浮点 (`#DIMF`) | 浮点/整数表达式 | 字符串 |

```erb
#DIM L_INT
#DIMS L_STR
#DIMF L_FLOAT

L_INT = 42                ; ✅ 整数赋值
L_INT = 3.14              ; ⚠️ 浮点赋给整数，截断为 3
L_STR = Hello             ; ✅ FORM 语法
L_STR '= "Hello"          ; ✅ 字符串表达式
L_STR = 42                ; ✅ FORM 语法："42"（数字作为字符串字面量）
L_FLOAT = 3.14            ; ✅ 浮点赋值
L_FLOAT = 10              ; ✅ 整数自动转为浮点
```

## #DIMS 初始化与赋值的语义差异

`#DIMS` 声明时的初始化 `=` 和赋值语句的 `=` 语义不同：

| 位置 | 语法 | 解析方式 | 是否支持 FORM 插值 |
|------|------|---------|-------------------|
| `#DIMS` 初始化 | `#DIMS S = "hello"` | **表达式求值** | ❌ 不插值 |
| 赋值语句 | `S = hello %NAME%` | **FORM 语法** | ✅ 插值 |

```erb
@MY_FUNC
#DIMS L_STR = "Hello %NAME%"     ; → "Hello %NAME%"（字面文本，不插值！）
    L_STR = Hello %NAME%         ; → "Hello 艾莉娜"（FORM 插值）
    L_STR '= "Hello %NAME%"      ; → "Hello %NAME%"（表达式，不插值）
RETURN
```

这是因为 `#DIMS` 初始化走 `ExpressionParser.ReduceArguments`（表达式语法），而赋值 `=` 走 `AnalyseFormattedString`（FORM 语法）。另外，`#DIMS` 没有 `'= ` 语法——初始化只能用 `=`，且必须是常量表达式。

> 源码参考：`ArgumentBuilder.cs` 中 `FORM_STR_ANY`（赋值 `=`）vs `ReduceArguments`（#DIMS 初始化）。

## 常见陷阱

| 陷阱 | 错误写法 | 正确写法 | 原因 |
|------|---------|---------|------|
| 字符串不加引号 | `S '= hello` | `S '= "hello"` | 不加引号会被当作变量名 |
| FORM 语法中意外插值 | `S = 100%` | `S = 100\%` 或 `S '= "100%"` | `%` 在 FORM 语法中是变量替换符 |
| 批量赋值用 `=` | `STR:0 = "a","b"` | `STR:0 '= "a","b"` | `=` 会将逗号作为 FORM 文本的一部分 |
| `==` 误用为赋值 | `A == 10` | `A = 10` | `==` 是比较运算符，赋值应用 `=` |
| 复合赋值批量 | `A:0 += 1,2,3` | `A:0 = 1,2,3` | 复合赋值不支持批量 |
| 赋值目标不是变量 | `A + B = 10` | 不允许 | 赋值左侧必须是变量 |
| #DIMS 初始化期望插值 | `#DIMS S = Hello {X}` | 赋值行写 `S = Hello {X}` | #DIMS 初始化走表达式，不插值 |
