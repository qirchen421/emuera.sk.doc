## 3つのファイルタイプ

ERABASIC プログラムは3つのファイルで構成されます：

| 拡張子 | 用途 | 処理順序 | 類比 |
|--------|------|----------|------|
| `.CSV` | データ定義（変数名マッピング、キャラデータ、配列サイズ） | **最初** | C の `.h` 宣言 + データベースシード |
| `.ERH` | ヘッダファイル（グローバル変数宣言、マクロ定義） | **次** | C の `.h` ヘッダファイル |
| `.ERB` | メインスクリプト（関数定義と実行コード） | **最後** | C の `.c` ソースファイル |

!!! important "処理順序は不可逆"

    CSV → ERH → ERB の処理順序は固定されています。つまり：

    - CSV で定義した変数名は、ERH と ERB の両方で使える
    - ERH で宣言したグローバル変数は、ERB で直接使える
    - ERB では CSV や ERH レベルの内容を定義できない

## CSV ファイル

CSV ファイルはデータ層の内容を定義し、エンジン起動時に最初に処理されます。

### 典型的なファイル構造

```
CSV/
├── variable_size.csv     ← 組み込み変数の配列サイズ
├── _replace.csv          ← 変数名置換マッピング
├── chara/
│   ├── chara0.csv        ← キャラ0のデータ
│   └── chara1.csv        ← キャラ1のデータ
├── item.csv              ← アイテムリスト
├── talent.csv            ← 素質リスト
└── abl.csv               ← 能力リスト
```

### variable_size.csv

組み込み変数の配列サイズを定義します：

```csv
BASE,100
TALENT,1000
ABL,100
EX,100
```

### _replace.csv

変数名置換マッピング。表示名を内部変数名にマップします：

```csv
体力,BASE:0
气力,BASE:1
```

### chara/*.csv

キャラデータ定義。各ファイルが1キャラを定義します：

```csv
; chara0.csv
名前,艾莉娜
CALLNAME,艾莉
BASE:0,1000
BASE:1,500
TALENT:0,1
```

## ERH ヘッダファイル

ERH ファイルはグローバル変数とマクロを宣言し、ERB より前に処理されます。

### 典型的なファイル構造

```
ERH/
└── VARIABLE.ERH
```

### 宣言構文

```erb
; グローバル整数変数
#DIM GAME_TURN, 100

; グローバル文字列変数
#DIMS SCENE_TEXT, 50

; グローバル浮動小数点変数
#DIMF GAME_SCORE, 100

; グローバル定数
#DIM CONST MAX_PARTY = 6

; セーブ跨ぎグローバル変数
#DIM GLOBAL HIGH_SCORE

; セーブ保存変数
#DIM SAVEDATA QUEST_FLAG, 100

; キャラデータ変数
#DIM CHARADATA CHARA_LEVEL

; マクロ定義
#DEFINE MAX_LEVEL 100
```

!!! warning "ERH 内の #DIM はグローバル宣言"

    ERH 内の `#DIM` が宣言するのは**グローバル変数**（`IsPrivate=false`）で、すべての ERB 関数からアクセスできます。
    ERB 関数内の `#DIM` が宣言するのは**プライベート変数**（`IsPrivate=true`）で、現在の関数のみがアクセスできます。

---

## ERB スクリプトファイル

ERB ファイルは関数定義と実行コードを含み、最後に処理されます。

### 典型的なファイル構造

```
ERB/
├── SYSTEM_TITLE.ERB      ← タイトル画面
├── SHOP.ERB              ← ショップ画面
├── TRAIN.ERB             ← 訓練画面
├── SHOW_STATUS.ERB       ← ステータス表示
└── COM/
    ├── COM0.ERB          ← コマンド0
    └── COM1.ERB          ← コマンド1
```

### ファイル名規則

- 拡張子は `.ERB` でなければならず、ファイル名は任意
- エンジンはファイル名順にすべての `.ERB` ファイルを読み込む
- 関数は `@` ラベル行で定義され、ファイル名とは無関係
- 同一関数を複数ファイルで重複定義してはならない

## 完全なロードフロー

```
エンジン起動
  │
  ├── 1. CSV ファイルの読み込み
  │     ├── variable_size.csv → 組み込み変数の配列サイズを設定
  │     ├── _replace.csv → 変数名マッピングを構築
  │     └── chara/*.csv → キャラデータを読み込む
  │
  ├── 2. ERH ヘッダファイルの読み込み
  │     └── VARIABLE.ERH → グローバル変数を識別子辞書に登録
  │
  ├── 3. ERB スクリプトファイルの読み込み
  │     ├── @ ラベル行を解析 → 関数表を構築
  │     ├── # プリプロセス行を解析 → プライベート変数を登録
  │     └── 命令行を解析 → 実行コードを生成
  │
  └── 4. @SYSTEM_TITLE を呼び出す（存在する場合）
        またはデフォルトのタイトル画面を表示
```
