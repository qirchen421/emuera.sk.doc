## 概要

代入文はERABASICで最も基本的な操作の一つです——値を変数に格納します。構文はシンプルに見えますが、ERABASICの代入にはいくつか異なる形式があり、それぞれ異なる場面に適しています：

| 代入形式 | 構文 | 適用型 | 説明 |
|---------|------|--------|------|
| 基本代入 | `X = 10` | 整数/実数 | 最も一般的な形式 |
| 文字列FORM代入 | `S = Hello %NAME%` | 文字列 | `%変数%` 文字列置換、`{変数}` 数値補間に対応 |
| 文字列式代入 | `S '= "Hello"` | 文字列 | 式評価、展開なし |
| 複合代入 | `X += 5` | 整数/実数/文字列 | 算術演算 + 代入 |
| インクリメント/デクリメント | `X ++` / `X --` | 整数/実数 | 前置または後置 |
| 一括代入 | `A:10 = 1,2,3` | 配列 | 連続要素への代入 |

!!! note "eramaker互換性"
    基本代入（`=`）、複合代入（`+=`/`-=`/`*=`/`/=`/`%=`）、文字列FORM代入はeramakerから存在する機能です。インクリメント/デクリメント（`++`/`--`）、文字列式代入（`'=`）、一括代入はEmueraの拡張機能です。

---

## パーサーが代入文を識別する仕組み

ERABASICのパーサーは、1行のコードに遭遇した時、以下の順序で判断します：

```
1. 行頭が ++ または -- ？ → 前置インクリメント/デクリメント文
2. 行頭が既知のコマンド名？ → コマンド文（PRINT、CALLなど）
3. いずれでもない → 代入文として解析を試みる
```

パーサーがコマンドではないと判断した場合：

1. `LexicalAnalyzer.Analyse` で代入先（等号左辺の変数）を読み取る
2. `LexicalAnalyzer.ReadAssignmentOperator` で代入演算子を読み取る
3. 残りの部分を式として解析する（等号右辺）

つまり、**代入文の左辺は変数でなければなりません**。式や定数は指定できません。

## 基本代入

### 整数代入

```erb
A = 100
MONEY = 500
FLAG:0 = 1
ABL:TARGET:0 = 3
```

等号の右辺には任意の整数式を指定できます：

```erb
A = 10 + 20
A = B * 2 + C
A = MAX(10, 20)
A = STRLEN("hello")
```

### 実数代入

```erb
#DIMF SCORE
SCORE = 3.14
SCORE = 10 / 3.0
```

!!! warning "整数除算と実数除算"

    `10 / 3` の結果は `3`（整数除算、小数切り捨て）ですが、`10 / 3.0` の結果は `3.333...`（実数除算）です。
    代入先の変数の型は、右辺の式の計算方法に影響しません。

## 文字列代入

文字列変数には2つの代入方法があり、動作が全く異なります：

### FORM構文代入（`=`）

`=` で代入すると、右辺はFORM構文として解析されます——`{変数}` が展開され、`%変数%` も置換されます：

```erb
NAME:0 = えりな
STR:0 = こんにちは、%NAME:0%！     ; → "こんにちは、えりな！"
STR:1 = 所持金：{MONEY}円           ; → "所持金：500円"
STR:2 = %NAME:0%の冒険              ; → "えりなの冒険"
STR:3 = NAME:0                      ; → "NAME:0"（%無しだとリテラル！）
STR:4 = CSVNAME(0)                  ; → "CSVNAME(0)"（関数は呼ばれない、そのままリテラル）
```

これはeramakerの元の動作です。eramakerでは、`STR:0 = %RESULTS%` は `RESULTS` の内容を `STR:0` に代入します。

### 文字列式代入（`'=`）

`'= ` で代入すると、右辺は**文字列式**として解析されます——FORM展開は行わず、式評価を行います：

```erb
STR:0 '= "こんにちは"               ; → "こんにちは"（リテラル）
STR:1 '= "Hello %NAME:0%"         ; → "Hello %NAME:0%"（展開なし！パーセントはリテラル）
STR:2 '= NAME:0 + "の冒険"          ; → "えりなの冒険"（文字列結合）
STR:3 '= TSTR:0 + "続行"            ; → 変数値 + "続行"
STR:4 '= CSVNAME(0)                 ; → キャラ0の名前（式評価で関数が呼ばれる）
```

### 2つの方法の比較

| | `=` (FORM構文) | `'= ` (式) |
|------|:---:|:---:|
| `{変数}` 展開 | ✅ | ❌ |
| `%変数%` 置換 | ✅ | ❌ |
| 文字列結合 `+` | ❌ | ✅ |
| 文字列リテラル `""` | 不要 | **必須** |
| 式関数の呼び出し | ❌ | ✅ |
| eramaker互換 | ✅ | ❌（Emuera拡張） |

!!! tip "選択の目安"

    - 単純な変数展開が必要 → `=` を使用（FORM構文の方が簡潔）
    - 文字列結合、関数呼び出し、複雑な式が必要 → `'= ` を使用
    - 迷った場合は、`'= ` + `""` で文字列を囲む方が安全（意図しない展開を防ぐ）

## 複合代入

複合代入演算子は、算術演算と代入を1ステップにまとめます：

```erb
X += 5          ; X = X + 5
X -= 3          ; X = X - 3
X *= 2          ; X = X * 2
X /= 4          ; X = X / 4
X %= 10         ; X = X % 10（剰余）
```

Emueraはビット演算の複合代入もサポートします：

```erb
X <<= 2         ; X = X << 2（左シフト）
X >>= 1         ; X = X >> 1（右シフト）
X |= 0xFF       ; X = X | 0xFF（ビットOR）
X &= 0x0F       ; X = X & 0x0F（ビットAND）
X ^= 0xAA       ; X = X ^ 0xAA（ビットXOR）
```

文字列変数も `+=` をサポートします：

```erb
STR:0 += "追加テキスト"      ; 文字列結合（Emuera拡張）
```

!!! warning "複合代入は一括代入に使用できません"

    ```erb
    ; ❌ エラー：複合代入は一括代入をサポートしません
    A:10 += 1,2,3

    ; ✅ 正しい：基本代入の一括形式を使用
    A:10 = 1,2,3
    ```

## インクリメントとデクリメント

### 後置形式（文）

```erb
X ++            ; X = X + 1
X --            ; X = X - 1
```

後置インクリメント/デクリメントは**独立した文**として使用し、式に埋め込むことはできません：

```erb
; ✅ 正しい：独立した文
X ++

; ❌ エラー：式に埋め込めない
A = X ++ + 1
```

### 前置形式（文）

```erb
++X             ; 前置インクリメント（独立した文として）
--X             ; 前置デクリメント（独立した文として）
```

前置インクリメント/デクリメントも独立した文です。パーサーは行頭で `++` または `--` を検出すると、前置インクリメント/デクリメント文として認識します。

!!! warning "前置インクリメント/デクリメントの厳格な規則"

    行頭の `++` または `--` の直後には変数名が続かなければなりません。変数以外が続くとエラーになります：

    ```erb
    ; ❌ エラー：++ の後に変数ではない
    ++ 5
    ++ (A + B)

    ; ✅ 正しい
    ++ A
    ++ FLAG:0
    ```

### 式の中のインクリメント/デクリメント

式の内部（代入の右辺、IF条件など）では、後置 `++`/`--` を使用できます：

```erb
A = X ++        ; A = X の現在の値、その後 X = X + 1
IF Y -- > 0     ; Y > 0 を判定、その後 Y = Y - 1
```

ただし、式の中で前置 `++`/`--` は使用**できません**：

```erb
; ❌ エラー：式の中で前置インクリメントは使用不可
A = ++ X
```

## 一括代入

配列変数に代入する際、カンマで区切って複数の値を指定し、連続する要素への一括代入ができます：

```erb
; A:10、A:11、A:12 にそれぞれ 1、2、3 を代入
A:10 = 1,2,3

; 二次元配列：DA:0:0、DA:0:1、DA:0:2 にそれぞれ代入
DA:0:0 = 1,2,3
```

!!! warning "一括代入の制限"

    1. **行をまたぐ代入はしない**：二次元配列の一括代入は自動的に行を切り替えません。`DA:0:0 = 1,2,3` は `DA:0:0`~`DA:0:2` にのみ代入し、`DA:1:0` には続きません
    2. **複合代入はサポートしない**：`A:10 += 1,2,3` は書けません
    3. **文字列の一括代入には `'= ` が必要**：

    ```erb
    ; ❌ エラー：= を使うと全体が1つのFORM文字列として扱われる
    STR:20 = いちご,メロン,ブルーハワイ
    ; → STR:20 = "いちご,メロン,ブルーハワイ"（1つの文字列）

    ; ✅ 正しい：'= で個別に代入
    STR:20 '= "いちご", "メロン", "ブルーハワイ"
    ; → STR:20 = "いちご", STR:21 = "メロン", STR:22 = "ブルーハワイ"
    ```

## `==` を代入演算子として使用する

ERABASICには歴史的な動作があります：`==`（通常は比較演算子）が代入位置に現れた場合、代入演算子 `=` として扱われます：

```erb
A == 10         ; A = 10 と同等（警告が表示される）
```

パーサーは代入位置に `==` を検出すると、警告を発しますが代入を実行します。これは初期のコードで `==` を代入に誤用することが頻繁にあったため、互換性のために残されています。

!!! danger "新しいコードで == を代入に使用しないでください"

    エンジンは `==` の代入を許容しますが、コードの可読性が低下し警告が発生します。代入には常に `=` を使用し、`==` は比較にのみ使用してください。

## 代入と型システム

ERABASICには3つの基本型があります：整数（Int64）、文字列（String）、実数（Double）。代入時には型が一致している必要があります：

| 代入先の変数型 | 許可される代入 | 許可されない代入 |
|--------------|-------------|---------------|
| 整数 (`#DIM`) | 整数式 | 文字列、実数（整数に切り捨て） |
| 文字列 (`#DIMS`) | `=` FORM構文 または `'= ` 文字列式 | 整数式 |
| 実数 (`#DIMF`) | 実数/整数式 | 文字列 |

```erb
#DIM L_INT
#DIMS L_STR
#DIMF L_FLOAT

L_INT = 42                ; ✅ 整数代入
L_INT = 3.14              ; ⚠️ 実数を整数に代入、3に切り捨て
L_STR = Hello             ; ✅ FORM構文
L_STR '= "Hello"          ; ✅ 文字列式
L_STR = 42                ; ✅ FORM構文："42"（数値は文字列リテラルとして扱われる）
L_FLOAT = 3.14            ; ✅ 実数代入
L_FLOAT = 10              ; ✅ 整数は自動的に実数に変換
```

## よくある落とし穴

| 落とし穴 | 誤った書き方 | 正しい書き方 | 理由 |
|---------|------------|------------|------|
| 文字列に引用符なし | `S '= hello` | `S '= "hello"` | 引用符なしは変数名として扱われる |
| FORM構文で意図しない展開 | `S = 100%` | `S = 100\%` または `S '= "100%"` | `%` はFORM構文で変数置換記号 |
| 一括代入で = を使用 | `STR:0 = "a","b"` | `STR:0 '= "a","b"` | `=` はカンマをFORMテキストの一部として扱う |
| == を代入に誤用 | `A == 10` | `A = 10` | `==` は比較演算子、代入には `=` を使用 |
| 複合代入で一括 | `A:0 += 1,2,3` | `A:0 = 1,2,3` | 複合代入は一括代入をサポートしない |
| 代入先が変数ではない | `A + B = 10` | 不可 | 代入の左辺は変数でなければならない |
