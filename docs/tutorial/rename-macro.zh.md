# Rename 宏：`[[名字]]` 编译期替换

!!! tip "本章要点"

    - `[[名字]]` 是基于 `CSV/_Rename.csv` 的**读取阶段整行文本替换**。左列＝替换后的值（通常是编号）、右列＝ERB 中书写的表记
    - 替换发生在词法分析与注释剥离**之前**。未登记的 `[[…]]` 会**编译报错**——拼写错误不会静默留到运行期（fail-fast）
    - 与 CSV／ERD／ALS 的标识符字典（名字→下标）是**两套机制**。替换结果是可嵌入表达式任意位置的常量文本

---

## Rename 是什么

Rename 是源自 EraMakerEx 的简易宏功能，把 ERB 中的 `[[名字]]` 表记替换为 `CSV/_Rename.csv` 中登记的值。初衷是"让脚本里的编号可以用名字来写"。

启用方式是配置项「使用 _Rename.csv」（**默认 NO**）。该配置未开启时读取含 `[[名字]]` 的 ERB，所有 `[[…]]` 都会编译报错。详见[配置项目](../Emuera/config.zh.md)。

## `_Rename.csv` 的书写格式

在 `CSV` 文件夹直下放置 `_Rename.csv`，每行为 `值, 名字` 的顺序：

```csv
; 左列 = 替换后的值（通常是编号）、右列 = ERB 中写的 [[表记]]
8,千百合
44,爱莲
44,マイ      ; 多个名字指向同一个值是合法的
```

规则：

| 规则 | 内容 |
|------|------|
| 注释行 | 以 `;` 开头的行被跳过（可用来停用某条登记） |
| 同名多行 | 右列重复时，**后读取的行生效**（字典只有一份） |
| 单一名字空间 | 整个文件是一张扁平字典。不同类别同名（例：料理与道具都有「冰淇淋」）会互相冲突——需要区分的一方加前缀（如 `ITEM_`）规避 |
| 编码 | 字符编码自动判别 |

## 处理流程

1. **启动时**：配置开启则读取 `_Rename.csv`，构建 `[[右列]]` → 左列 的字典
2. **读取时**：用正则 `\[\[.*?\]\]` 逐行扫描 ERB，命中字典则把该处替换为值的文本。该替换在**注释剥离之前**进行，因此注释里的 `[[名字]]` 同样会被替换
3. **词法分析时**：仍未被替换的 `[[…]]` 会**编译报错**

替换是纯文本替换，替换结果（`8` 等编号文本）直接嵌入表达式。因此替换后的值可以参与[常量折叠](constant-folding.zh.md)与 `SELECTCASE` 跳转表优化。

## 名字→值的机制比较

ERABASIC 中有多种"用名字指代编号"的机制，角色各不相同，不要混淆：

| 机制 | 定义文件 | 记法 | 未登记时 | 备注 |
|------|---------|------|---------|------|
| CSV 标识符文件 | `CSV/变量名.csv` | `ITEM:名字`、`GETNUM` | 运行期无法解析（`GETNUM` 返回 -1） | 引擎内置变量的名字定义 |
| ERD | `ERB/变量名.erd` | 同上 | 同上 | `#DIM` 广域变量的名字定义 |
| ALS（别名） | 与 `.erd`/`.csv` 同名的 `.als` | 同上（可用别名） | 同上 | 为同一下标追加别名 |
| **Rename（本页）** | `CSV/_Rename.csv` | `[[名字]]` | **编译报错** | 把值文本嵌入表达式的任意位置 |
| `#DIM CONST` / `#DEFINE` | ERH 内 | 裸标识符 | 编译报错 | 代码侧定义的常量 |

标识符字典系（CSV/ERD/ALS）只服务于"**变量的名字下标**"，由 `变量:名字` 和 `GETNUM` 消费；而 Rename 不绑定特定变量，`CASE` 的值、算术式、数组下标等**表达式的任意位置**都能嵌入。详见[变量标识符：CSV／ALS／ERD](variable-declaration.zh.md#identifiers)。

## 用法示例

```erb
; 用名字写 CASE 的值（[[饭团]] → 101 被替换）
SELECTCASE FLAG:料理
    CASE [[饭团]]
        PRINTL 是饭团

; 算术式中（偏移 + 角色编号）
CASE DISH_CHARA_OFFSET + [[千百合]]    ; → DISH_CHARA_OFFSET + 8

; 简单确认值
PRINTV [[千百合]]    ; → 8
```

在整数比较的语境下，注意 `"名字"` 字符串字面量与 `[[名字]]` 不能混用：

```erb
; ❌ "みかん" 是字符串字面量——ARG 是整数时永远不会相等
SIF GROUPMATCH(ARG, [[りんご]], "みかん")

; ✅ 统一全部使用 [[名字]]
SIF GROUPMATCH(ARG, [[りんご]], [[みかん]])
```

## 常见陷阱

| 陷阱 | 现象 | 对策 |
|------|------|------|
| `"名字"`（字符串）与 `[[名字]]`（值）混用 | 整数比较语境下字符串字面量永远不会相等 | 比较对象统一为 `[[名字]]` |
| 名字未登记 | 编译报错（fail-fast） | 在 `_Rename.csv` 追加 `值,名字` 行 |
| 不同类别同名冲突 | 后读取的行生效，解到非预期的编号 | 用前缀（如 `ITEM_`）划分名字空间 |
| 注释里的 `[[名字]]` | 替换先于注释剥离，注释也是替换对象 | 把名字写进注释时须留意 |
| 配置未开启 | 所有 `[[…]]` 编译报错 | 启用「使用 _Rename.csv」 |
