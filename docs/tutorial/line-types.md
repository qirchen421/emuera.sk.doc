## 4種類の行タイプ

ERABASICは**行駆動**言語です——エンジンは行ごとに解析し、各行は以下の4種類のいずれかに属します：

| 行タイプ | 識別子 | C# クラス | 説明 |
|--------|------|-------|------|
| **関数ラベル行** | `@FUNC_NAME` | `FunctionLabelLine` | 関数の入口。関数名と引数を定義 |
| **プリプロセッサ行** | `#DIM` / `#FUNCTION` 等 | `FunctionLabelLine` のサブ情報 | 変数の宣言、関数タイプのマーク |
| **命令行** | `PRINT` / `CALL` / `A = 1` 等 | `InstructionLine` | 命令を実行 |
| **Gotoラベル行** | `$LABEL_NAME` | `GotoLabelLine` | ジャンプ先 |
| **空行・コメント行** | `;` で始まる行または空行 | `NullLine` | 無視される |

## 関数ラベル行（@行）

関数ラベル行は `@` で始まり、関数の名前と引数を定義します：

```erb
@MY_FUNC(ARG:0, ARG:1)
@GREET(ARGS:0)
@CALC(X, Y)
@EVENT_TRAIN
```

### 関数ラベル行の構成

```
@FUNCTION_NAME(PARAM1, PARAM2, ...)
↑  ↑           ↑       ↑
│  │           │       └── 引数リスト（カンマ区切り）
│  │           └────────── 関数名
│  └────────────────────── @ プレフィックス（必須）
└───────────────────────── 関数ラベル行識別子
```

### 引数の書き方

| 引数の書き方 | 意味 | #DIM 宣言の要否 |
|---------|------|----------------|
| `ARG:0` | 組み込み整数引数 | 不要（組み込み） |
| `ARGS:0` | 組み込み文字列引数 | 不要（組み込み） |
| `ARGF:0` | 組み込み浮動小数点引数 | 不要（組み込み） |
| `X` | プライベート変数引数 | **必要** `#DIM X` |
| `VARIADIC ARG:0` | 可変整数引数 | 不要（組み込み） |

## プリプロセッサ行（#行）

プリプロセッサ行は `#` で始まり、`@` 関数ラベル行の後、最初の命令行の前に記述する必要があります。複数の `#` 行を連続して記述でき、順序は問いません。空行とコメント行（`;`）は `#` 行の連続に影響しません。

### 位置ルール

```erb
@MY_FUNC(ARG:0, ARG:1)     ← @ ラベル行
#DIM L_TEMP, 10             ← #DIM 宣言（@ 行の後）
; これはコメント（# 行の連続に影響しない）
#FUNCTION                    ← #FUNCTION 宣言（コメントの後でも有効）
    PRINTL 開始              ← 最初の命令（# 行はこれより前にある必要がある）
    L_TEMP:0 = ARG:0 + ARG:1
RETURN L_TEMP:0
```

!!! danger "# 行の位置エラーは最もよくあるコンパイル警告"

    ```erb
    ; ❌ 間違い：#DIM が関数本体の途中にある
    @MY_FUNC
        PRINTL 開始
        #DIM X, 10        ; → 警告: "#行は関数宣言の直後のみ使用可能"

    ; ✅ 正しい：すべての # 行は @ 行の後、実行文の前に記述
    @CALC(X, Y)
    #FUNCTION
    ; これはコメント（# 行の連続に影響しない）
    #DIM X
    #DIM Y
        RETURNF X * Y
    ```

### プリプロセッサ指令の分類

| 指令 | 用途 | スコープ |
|------|------|--------|
| `#DIM` | 整数プライベート変数の宣言 | 関数内 |
| `#DIMS` | 文字列プライベート変数の宣言 | 関数内 |
| `#DIMF` | 浮動小数点プライベート変数の宣言 | 関数内 |
| `#REF` / `#REFS` / `#REFF` | スカラー参照の宣言 | 関数内 |
| `#FUNCTION` / `#FUNCTIONS` / `#FUNCTIONF` | 式関数タイプのマーク | 関数レベル |
| `#LOCALSIZE` / `#LOCALSSIZE` / `#LOCALFSIZE` | LOCAL 配列サイズの設定 | 関数レベル |
| `#PRI` / `#LATER` / `#SINGLE` / `#ONLY` | イベント関数の優先度修飾 | イベント関数 |

## 命令行

命令行は関数の本体であり、実際の操作を実行します。

### 命令行の種類

| 種類 | 例 | 説明 |
|------|------|------|
| 出力命令 | `PRINTL こんにちは` | テキストを出力 |
| 入力命令 | `INPUT` | ユーザー入力を待機 |
| 代入文 | `X = 10` | 変数に値を代入 |
| 関数呼び出し | `CALL MY_FUNC(1, 2)` | 関数を呼び出し |
| 制御フロー | `IF` / `FOR` / `REPEAT` | 条件とループ |
| 戻り | `RETURN` / `RETURNF` | 関数から戻る |

!!! warning "命令構文 vs 式構文"

    命令行では、関数名の**直後にスペースまたはタブが必要**です。`FUNC(args)` のような括弧構文は**独立した命令行として使用できず**、式の中でのみ使用可能です（例：`X = FUNC(args)` や `IF FUNC(args) > 0`）。

    ```erb
    ; ✅ 命令構文（スペース区切り）
    STRLEN "hello"

    ; ❌ 括弧構文を独立コマンドとして使用 → 解析失敗！
    STRLEN("hello")
    ```

    詳細は[命令 vs 式](command-vs-expression.md)を参照。

### 代入演算子

```erb
; 整数・浮動小数点代入
X = 10                    ; 基本代入
X += 5                    ; 加算代入
X -= 3                    ; 減算代入
X *= 2                    ; 乗算代入
X /= 4                    ; 除算代入
X ++                      ; インクリメント
X --                      ; デクリメント

; 文字列代入
S = Hello %NAME%          ; フォーマット文字列（%変数% 文字列置換）
S '= "Hello"              ; 式評価（補間なし）
S += " World"             ; 文字列結合
```

!!! warning "文字列代入の = と '= は意味が異なる"

    | 演算子 | 意味 | 例 |
    |--------|------|------|
    | `=` | フォーマット文字列（`%変数%` 文字列置換、`{変数}` 数値補間） | `S = Hello %NAME%` → `Hello エリナ` |
    | `'= ` | 式評価（補間なし） | `S '= "Hello %NAME%"` → `Hello %NAME%` |

### コメント

```erb
; これはコメント（行頭 ;）

; ✅ 行末コメント：プリプロセッサ行、条件制御文、一般命令行
#DIM L_COUNT, 10      ; ローカル配列の宣言
#FUNCTION              ; 式関数のマーク
SIF RESULT == 0        ; 結果がゼロならスキップ
    RETURN 0
CALL MY_FUNC           ; 関数の呼び出し
LOCAL = 10 + 20        ; 代入式

; ❌ PRINT 系命令は行末コメントに非対応
; PRINTL は ; 以降の内容を文字列としてそのまま表示する
PRINTL こんにちは    ; これはコメントではない、"こんにちは    ; これはコメントではない" が表示される
```

!!! warning "eramaker のコメント制限"

    eramaker では行末にコメントを書けません（`;` 以降の内容が命令として実行される）。
    Emuera はこの制限を緩和し、行末の `;` 以降の内容は無視されます——ただし **PRINT 系命令は例外**で、行末の残り内容を文字列引数として扱うため、`;` がそのまま表示されます。

## Gotoラベル行（$行）

Gotoラベル行は `$` で始まり、`GOTO` 命令のジャンプ先となります：

```erb
@MY_FUNC
$LOOP_START
    PRINTL 続けますか？
    INPUT
    SIF RESULT == 0
        GOTO LOOP_START
RETURN
```

!!! tip "GOTO はできるだけ使わない"

    ERABASIC には IF/SELECTCASE/FOR/REPEAT/WHILE などの構造化制御フローがあり、
    ほとんどの場合 GOTO は不要です。GOTO は主に旧コードとの互換性のために使用します。

---

## 行構造の全体像

1つの完全な関数は、これら4種類の行タイプが決まった順序で構成されます：

```erb
@MY_FUNC(ARG:0, ARG:1)       ← 1. @ ラベル行（関数の入口）
#DIM L_TEMP, 10               ← 2. # プリプロセッサ行（宣言、@ 行の後）
#FUNCTION                      ← 2. # プリプロセッサ行（タイプマーク）
    L_TEMP:0 = ARG:0 + ARG:1  ← 3. 命令行（実行）
    IF L_TEMP:0 > 10          ← 3. 命令行（制御フロー）
        PRINTL 10より大きい    ← 3. 命令行
    ENDIF                      ← 3. 命令行
$RETRY                         ← 4. $ Goto ラベル行
    RETURNF L_TEMP:0           ← 3. 命令行（戻り）
```
