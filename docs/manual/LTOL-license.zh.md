## 序言   
本页面记述和解释了由志愿者整理的口上许可证方案  
**Limited Time Open Licence**/**时限开放许可证**(以下简称**LTOL许可证**)。  
该许可证旨在保护口上作者的权利，同时也考虑了修改者的便利性。  

<span style="color:red">但是，采用此许可证并非义务。</span>  

对于未声明采用LTOL许可证的口上，  
不得依据此许可证进行处理，请注意。  

---  

## 许可证正文  


```  
1.关于此许可证  
　此许可证明确用于保护口上中包含的台词等。  
　以下情况禁止。  

1-a. 组入其他许可证的情况。  
　将此许可证写成的台词等移植到其他许可证的口上中  
　在移植目的地的许可证中制定该许可证。  
　但仅限于对派生物具有许可证效力的。  
　防止许可证污染。  

1-b. 修改许可证的情况。  
　将标注此许可证的口上替换使用到其他许可证。  
　此许可证制定的口上不能修改许可证，除非是许可证版本升级。  
　此许可证一旦标注即生效，不能切换到其他许可证。  

1-c. 侵犯其他许可证的行为  
　此许可证写成的口上不能以侵犯其他许可证权利的形式  
　添加代码。  
　仅限于原许可证允许移植等的情况。  

2. 关于修改等  
　作者可以允许或拒绝修改等。  
　但若未特别标注，则视为允许。  

3. 许可证期间  
　标注此许可证的有效期和失效条件。  

3-a. 有效期  
　此许可证自标注之日起一年为有效期。  
　但当口上更新等进行版本升级时，再延长一年。  

3-b. 许可证失效  
　有效期截止，或采用此许可证的作者失联  
　半年后此许可证失效，成为免费许可证。  
　但失效后作者回归的情况下，以最后标注的口上版本作为作者的著作物。  
　之后的派生物不能主张许可证。  
```

## 解说篇  

### 第1项 关于应限制的事项  

#### 关于1-a  
此条款是指此许可证（以下简称A）对于对方许可证（以下简称B）  
在明确记载派生物也适用B许可证条款的情况下禁止。  
即，从A许可证对派生物不适用许可证的许可证情况下允许移植。  
此外，无许可证及免费许可证的情况也允许移植。  
补充：此许可证止于此许可证。  
不会感染其他许可证。  

#### 关于1-b  
此许可证写成的口上除许可证自身的版本升级或降级外，不能修改许可证。  
修改许可证的情况下，通过作者的追记等，或在允许修改的情况下  
由修改者进行许可证的修改。  
在未补充追加的状态下，不允许修改许可证。  

#### 关于1-c  
这是常识性的话题，但呼吁不要侵犯他人许可证的事项。  
禁止有移植等禁止的情况下的移植等。  

---  

### 第2项 关于修改的允许及拒绝  
对于拒绝的情况，应明确标注。  
未明确的情况下，如果定为拒绝条款，会导致未明确标注许可的情况下  
统一成为拒绝的事故，因此避免这种情况。  
希望想拒绝的话要明确标注拒绝。  

---  

### 第3项 关于许可证期间  

#### 关于3-a. 有效期  
口上添加等时，此许可证标注或捆绑的情况下  
从口上文件创建日起1年有效期。  
即，每次更新期限都会更新。  
以前的版本也受到许可证保护。  

#### 关于3-b. 失效条件  
口上未更新有效期截止的情况下，该口上变为免费。  
但持续更新的前版本等许可证仍有效。  
另外，虽有有效期但完全无法联系到作者的情况下，从口上更新日起半年失效变为免费。  
但作者回归的情况下，以标注此许可证及捆绑的版本作为著作物。  
之后的派生物不能主张许可证。  
补充：作者能联系上的状态下，从最终创建日起有1年的更新宽限期。

## FAQ篇  

### Q1. 此许可证制定的意义是什么？  
A1. 为了解决无法联系到口上作者导致无法维护，  
想添加内容但不知如何处理的疑问而制定。  

### Q2. 想上传他人添加版……  
A2. 若未写明拒绝添加修改则OK。  
但礼仪上建议在帖子等处联系。  

### Q3. 用GNU GPL许可证制作口上，能从这个许可证移植吗？  
A3. 抵触1-a条款，不行。  

### Q4. 想维护……  
A4. 如A2所述，未明确拒绝的情况下OK。  
能联系上的话不妨在帖子等处联系作者。  

### Q5. 1-a条款不太明白……  
A5. 简单说就是移植目的地的许可证对  
从此口上产生的口上等适用许可证的许可证。  
将此许可证作为A，移植目的地许可证作为B。  
其他作为C。  

```  
A原→B移植目的地→B派生物  
```  

这种许可证对移植目的地来说是NG。  

```  
A原→B→C派生物  
```  

这种是OK。  

顺便此许可证不会适用于移植目的地。  
（不会感染）
