## 编程术语

### git
版本管理系统。可以在本地保存修改历史的同时，上传到远程仓库这种在线项目，进行备份。  
在多人制作时尤其能发挥其优势，但个人制作时也有确认修改部分和回滚等便利功能，学会使用并不会吃亏。  
详情请参见[此页面](HowToUseGit.zh.md)。  


### VSCode(VSC)
可用于编程的IDE(集成开发环境)。简单来说是一个应用程序。  
免费使用且功能丰富。安装扩展功能后会更加便利。  
详细的安装方法请参见[此页面](erawiki-ERBmanual.md#vscode)。  

### 上传器
也称为loda。上传文件，让任何人都能下载的服务。当然也可用于免费游戏的发布。  
**没有永久服务的保障，era圈子中过去也多次出现主要上传器关闭或故障无法使用，导致许多变体、口上、补丁丢失的情况。**  
当然要在本地电脑保留数据，通过使用多个上传器也可以分散风险。最近也有从git仓库创建下载链接的方法。  

### 缩进
美化源代码外观的空格。大多数文本编辑器按Tab键即可输入。  
实际上不影响运行，但在IF语句和SELECTCASE语句等需要ENDIF和ENDSELECT等关闭的指令中，用于明确配对关系。  

### ESP(超能力)
"这个运行不了啊""这个怎么做啊？"等，面对提问者说明不足的情况，猜测其背景进行应对的能力者。  
当然现实世界中几乎没有ESP。向他人提问时，请附上自身环境、错误日志等详细说明。  

### 函数
源代码的分割单位之一。类似于将文件视为文件夹后再进一步分割文件的概念。  
Emuera中没有类或命名空间等概念，以`@～`开头的函数是源代码中唯一且最小的单位。  

### 樱花编辑器
文本编辑器之一。比Windows标准搭载的记事本功能丰富且轻量。  
通过设置可用于编程，在era制作中也会使用。  
下载及详细说明请参见[官方网站](https://sakura-editor.github.io/)。  

### 意大利面(代码)
滥用冗长表达、`CALL`、魔法数字导致的可读性极低的源代码。  
各种要素恶意纠缠无法解开的状态被比喻为意大利面的贬义称呼。  
当然源代码越整洁越好，但如上所述这是贬义称呼，因此对他人说"这是意大利面(代码)"并不太礼貌。  
作为补丁作者进行重构是最不容易引起争议的。  

### 黑盒
源代码内容不明确但能运行的程序。  
在era中，以其他变体为基础，或移植函数等情况中，"不了解内部但能使用功能"的情况较多。  
这对开源的era来说很方便，但另一方面，"发现了未知错误""以超出作者预期的方式使用导致无法正常获得结果""想要进一步改造"等情况时，因不了解内容导致制作者无法应对。  
补充说明，黑盒这个词本身几乎没有负面含义。  

### 变量
保存数据的概念。有称为"类型"的各种种类，处理的数据不同。  
Emuera中类型只有"数值型(int)"和"字符串型(str)"。  
数值型也兼具bool型，值为0时表示假(false)，其他情况表示真(true)。  

### 魔法数字
只有写源代码的人才知道用途的说明不足的数字、变量。  
而且作者自己日后回顾时也常常不知道其含义。  
还包括一字符变量或`LOCAL`、`ARG`等。大量使用这些会使变量用途不明，也成为黑盒的原因。  
基本上不推荐，现在有了可以给变量命名的功能，建议根据用途声明合适名称的变量再使用。  
另外，大量使用魔法数字时虽然**在程序上能正常运行，但人无法解读的源代码**也有其麻烦的一面，这也是程序领域中重构被轻视的原因之一。  

### 指令
在era源代码中执行某种动作的指令。调用函数、添加角色、显示文章等。  
可用指令一览请参见[此页面](../Reference/README.zh.md)。  

### 无限循环
使用循环指令时因某种原因循环无法结束的现象。大多数情况是程序错误造成的。  
Emuera中准备了失效保护，当循环持续一定时间以上时会停止运行。  
不过偶尔也会出现低性能PC运行处理重的代码、或源代码本身就复杂循环次数非常多等情况触发上述失效保护。  
循环次数越少越好，能在多大程度上优化这个处理可以说是展现技能的机会。  

### 重构
整理源代码的工作。  
通过进行重构，源代码的维护性和可读性会提高，因此在持续的变体制作中非常重要。  
具体来说包括"将相同处理合并到一个函数中""给变量命名使其用途明确""减少循环处理的浪费以提高运行速度""用用途明确的指令·表达式函数替代现有处理""根据文件内容更改文件名"等。  
但重构需要与从头创建源代码相同的劳动量，且运行本身不变，玩家几乎感受不到，因此相对于重要性常被忽视。  
~~另外多数情况下还会减小文件大小。与希望通过文件大小判断变体或口上规模的用户不太合拍。~~  
对程序员来说可以说是永恒的课题。  

### 异常
程序错误之一。引用无值变量等时会发生。  
在era制作中的错误不称为异常，因此出现此词时指的是Emuera本身的错误。  

## era相关

### CSV
"Comma Separated Value"的缩写文件扩展名。与ERB不同，这是各种应用程序使用的文件格式。  
因此可以用Excel等应用程序编辑，但可能混入多余符号等，因此不推荐。  
ERB用于编写源代码，而此格式用于预先定义各种数据（角色数据、变量名等）。  

### Emuera
基于下述eramaker增加功能等的派生游戏引擎。现在已经成为了主流。  
是开源的，除本wiki主要处理的Emuera.NET EM+EE外，国内外还有各种版本。  
[官方Emuera的OSDN](https://ja.osdn.net/projects/emuera/wiki/FrontPage)(可能连接困难)  

### eramaker
era的原版源头。由Circle Baku制作的游戏制作引擎。  
**初版于2005年12月12日。**  
[漠々ト、獏/erakanonのページ](https://cbaku.com/b/2010/12/eramaker/)  

### ERB
"ERaBasic"的缩写(有各种说法)文件扩展名。era的源代码主要写在此扩展名的文件中。  
基本上是era专用的扩展名，不会在其他应用程序中使用。从Windows设置开启显示扩展名选项后可以修改。  
在Visual Studio Code等IDE上可以生成无扩展名文件，所以使用扩展名".ERB"。  

### NO
角色CSV中记载的角色编号。每个角色的唯一数字，也在[CSV参考系指令](../Reference/CSV_STATUS.zh.md)中使用。  
基本上是固定值，不会变动。与注册编号(ID)容易混淆，但其实是不同的。制作新手需注意。  

### SHOP
游戏启动时显示的画面是标题画面，之后游戏开始后显示的主要菜单部分，惯例称为SHOP画面。  
源于eramaker时代构成此画面的函数名称就叫"SHOP"。  

### 你
大多数变体中注册在角色编号0的角色。大多是男性，但也有女性或可自定义的情况。  
在二次创作色情作品中，杆役变成路人的情况很多，era也继承了这一点。另外，在梦题材中主人公是"你"也很重要。  
在享受角色间配对玩法中，这个角色几乎变成不需要的角色。  

### 一字符变量
A～Z可用的单字母变量。int(数值)型。  
由于可以在函数间保持值，因此在限制较多的eramaker中很受欢迎。  
但在RETURN返回值规格扩展、变量声明功能搭载的Emuera中，由于严重影响源代码可读性，许多变体中都在避免使用。  
其原因是"变量用途难以理解""毕竟只有26种，复杂处理时会在某处发生变量冲突"等缺乏唯一性造成的。  
~~以旧变体为基础的变体中仍大量使用一字符变量，但重构需要大量劳力，因此对变体制作者提出过高要求是禁止的。~~  

### 角色注册编号范围外
era中最常见的错误。引用不存在角色状态时发生。  
`TARGET`为-1、循环过多、角色引用变量错误、角色引用变量意外值等原因多样。  
事前将`TARGET`或角色引用变量与`CHARANUM`(角色数)比较等可以预防。  

### 口上
era默认状态下往往只实现了正文。在这样的游戏中给角色添加专用台词的系统称为口上。  
有通用口上和专用口上两种，通用口上如其名参考角色素质等从几个模式显示口上。因此偶尔会发生"这个角色不会说这样的话"。  
专用口上是为该角色制作的口上，能营造出(虽然理解不同)角色真正说话般的商业色情游戏氛围。  
问题是两者制作都需要**大量劳力和时间、写作能力**，因此能制作这些的口上作者需求非常高。  

### 式中函数
在erabasic中函数本来是用`CALL`调用的，但不用`CALL`等而在表达式中也能返回数值或字符串的函数称为表达式函数。  
与普通函数一样，将多次使用的冗长处理总结为函数，用于复杂计算后只获取结果(数值)、根据场景改变的文本(字符串)等场合。  
表达式函数的详细规格请参见[此页面](../Emuera/in_expression_function.zh.md)。  

### 注册编号(ID)
ADDCHARA系列指令添加的角色分配的编号。从0开始，始终按前移方式处理。  
TARGET和ASSI也用注册编号指定。与NO不同，不是角色专属，会因DELCHARA或SORTCHARA而变动。  

### 变体
在eramaker或Emuera中运行的游戏总称。所有追溯源头都是从erakanon这个基础游戏派生(Variant)的，因此称为变体。  
在英语圈中也常称为eragame(s)。
