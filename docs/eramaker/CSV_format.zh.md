# eramaker的CSV书写格式

**本页记载的是eramaker的相关信息。与现行Emuera的规格存在部分差异。**

## 基本信息

### 关于CSV文件

在eramaker.exe的直下层放置名为CSV的文件夹。
CSV文件包括以下几种。

|文件名|说明|
|:--|:--|
|GameBase.csv|注册游戏的基本数据。|
|Palam.csv|注册调教中参数（快C、痛苦、反感等）。|
|Abl.csv|注册能力（V感觉、奉仕精神、施加倾向等）。|
|Talent.csv|注册资质（胆怯、自制心、恢复快等）。|
|Mark.csv|注册刻印（快乐刻印、耻辱刻印等）。|
|Exp.csv|注册经验（V经验、自慰经验等）。|
|Train.csv|注册调教命令（舔阴、口交、鞭子等）。|
|Item.csv|注册道具（振动棒、针等）。|
|Str.csv|注册游戏中使用的各种文章。|
|CharaXX.csv|注册角色的初始数据。Emuera中可以用任意数字指定|

### CSV文件的写法

所有CSV文件中：

- 第1列的第1个字符为半角;（分号）时，该行会被忽略。空行也会被忽略。

	**例**

	;体力与气力的设定
	基础,0,2000
	基础,1,1000

	;能力的设定
	能力,0,2

- 输入数值时请使用半角字符。

**正**

```
121,双儿
```

**误**

```
１２１,双儿
```

- 字符串用""包裹后将无法正常运作。这似乎是OpenOffice等的默认设置。

**正**

```
0,顺从
1,欲望
2,技巧
```

**误**

```
0,"顺从"
1,"欲望"
2,"技巧"
```

关于设定方法，请参阅您使用的表格软件帮助。

## 各文件的格式

### `GameBase.csv`的格式

在第1列写入命令，在第2列及之后写入数据。

- コード,(数值)
    - 将游戏代码设为(数值)。这是用于防止误加载其他游戏的存档数据。(数值)可以是任意值。

- バージョン,(数值)
	- 将游戏版本设为(数值)。画面上显示的是(数值)除以1000的结果（100则显示0.10）。初始状态下，不会读取不同版本保存的存档数据。

- タイトル,(字符串)
	- 将游戏标题设为(字符串)。在启动时显示。

- 作者,(字符串)
	- 将游戏作者设为(字符串)。在启动时显示。

- 製作年,(字符串)
	- 将游戏制作年设为(字符串)。在启动时显示。因为不是数值，所以也可以写成2005-2006等格式。

- 追加情報,(字符串)
	- 将游戏的追加信息设为(字符串)。在启动时显示。

- 最初からいるキャラ,(数值)
	- 设定游戏开始时（除主角外）存在的角色。用于era light等那种从一开始调教角色就已确定的游戏。(数值)指定角色编号。例如指定1则读取Chara01.csv，指定12则读取Chara12.csv。

- アイテムなし,(数值)
	- 将(数值)设为1的话，即使是需要道具的调教（如振动棒），也可以在无道具状态下进行调教。制作没有道具概念的游戏时，请设为1。

- バージョン違い認める,(数值)
	- 如果存档数据的版本在(数值)以上，即使版本不同也可以读取。在进行不影响整体的版本升级时，请设置此项。

	**例**

	```
	;可以读取版本1.20之后的存档数据
	版本差异认可,1200
	```

### Palam.csv的格式

- 第1列写入参数编号，第2列写入参数名。
- 参数编号从0开始，建议不要留空号。
- 参数编号最高为99，Emuera中可以通过`VariableSize.csv`修改上限。

### Abl.csv的格式

- 第1列写入能力编号，第2列写入能力名。
- 能力编号从0开始，建议不要留空号。
- 能力编号最高为99，Emuera中可以通过`VariableSize.csv`修改上限。

### Talent.csv的格式

- 第1列写入资质编号，第2列写入资质名。
- 可以留空号。
- 资质编号最低为0，最高为99，Emuera中可以通过`VariableSize.csv`修改上限。

### Mark.csv的格式

- 第1列写入刻印编号，第2列写入刻印名。
- 刻印编号从0开始，建议不要留空号。
- 刻印编号最高为99，Emuera中可以通过`VariableSize.csv`修改上限。

### Exp.csv的格式

- 第1列写入经验编号，第2列写入经验名。
- 可以留空号。
- 经验编号最低为0，最高为99，Emuera中可以通过`VariableSize.csv`修改上限。

### Train.csv的格式

- 第1列写入命令编号，第2列写入命令名。
- 可以留空号。
- 命令编号最低为0，最高为99，Emuera中可以通过`VariableSize.csv`修改上限。

### Item.csv的格式

- 第1列写入道具编号，第2列写入道具名，第3列写入道具价格。
- 可以留空号。
- 道具编号最低为0，最高为99，Emuera中可以通过`VariableSize.csv`修改上限。

### Str.csv的格式

- 第1列写入字符串编号，第2列写入字符串。
- 字符串长度基本上没有限制。
- 可以留空号。
- 字符串编号最低为0，最高为19999，Emuera中可以通过`VariableSize.csv`修改上限。

### CharaXX.csv的格式

- 番号,(数值)
	- 将角色编号设为(数值)。在制作角色之间的相性、同一角色的特别版本时很重要。

- 名前,(字符串)
	- 将角色名字设为(字符串)。字符串长度基本上没有限制，但过长可能会导致显示混乱。

- 呼び名,(字符串)
	- 将角色的称呼设为(字符串)。用于有昵称的角色。
	- 字符串长度基本上没有限制，但过长可能会导致显示混乱。

- 基礎,(数值1),(数值2)
	- 将角色的基础参数第(数值1)项设为(数值2)。
	- 示例游戏中，0是体力，1是气力，2是射精槽。
	- (数值1)最低为0，最高为99，Emuera中可以通过`VariableSize.csv`修改上限。

	**例**

	```
	;体力2000，气力1000
	基础,0,2000
	基础,1,1000
	```

- 能力,(数值1),(数值2)
	- 将角色的初始能力第(数值1)项设为(数值2)。
	- (数值1)请使用Abl.csv中指定的能力编号。
	- (数值2)没有特别限制，示例游戏中设为0到5。

- 素質,(数值)
	- 给角色添加第(数值)个资质。
	- (数值)请使用Talent.csv中指定的资质编号。

- 経験,(数值1),(数值2)
	- 将角色的初始经验第(数值1)项设为(数值2)。
	- (数值1)请使用Exp.csv中指定的经验编号。

- 相性,(数值1),(数值2)
	- 将对第(数值1)个角色的相性设为(数值2)。
	- (数值1)请使用CharaXX.csv中各自指定的角色编号。
	- (数值2)以100为标准，低于此值则相性差，高于此值则相性好。

- 助手,(数值)
	- 将(数值)设为1的话，初始状态就被当作助手对待。

- フラグ,(数值1),(数值2)
	- 将第(数值1)个角色标志设为(数值2)。
	- (数值1)最低为0，最高为999，Emuera中可以通过`VariableSize.csv`修改上限。
	- 角色标志可以根据游戏制作者的创意自由使用。示例游戏中，将第0个标志为1的角色视为"特别角色"。
	- （※虽然叫标志，但只要是整数值，0和1以外的值也可以使用）

## 了解后会很有用的知识

### 关于Str.csv中的***和+++

- 示例游戏era light的Str.csv中，会出现很多***和+++等。在游戏内，它们应该分别被转换为"明里"和"浩之君"。
- 要完全理解这一点需要ERA BASIC的知识，但暂且知道***是被调教的角色的名字、+++是主角的称呼、$$$是被调教的角色的称呼就可以了。
- 示例游戏erakanon中有助手系统。///是助手的名字，===是当时正在调教的人（主角或助手）的称呼。
