# Emuera使用方法

## 运行环境
需要.NET Framework 4.5环境。(EM+EE需要7.0)
已停止支持XP、Vista。已在Windows 10、11上确认可运行

如果出现"应用程序未能正确初始化"的错误而无法启动，请安装.NET Framework 4.5。
请从Microsoft网站下载并安装.NET Framework 4.5运行时。

## 使用方法
请将`EmueraXXX.exe`放入与`eramaker.exe`相同的文件夹中启动。
(XXX中包含表示版本的数字，根据环境可能不显示.exe)
如果无法启动，请阅读"运行环境"章节。
启动后立即生成`emuera.config`，如果错误终止则生成`emuera.log`。

基本操作与`eramaker.exe`几乎相同，但可以使用鼠标操作。
请用鼠标指向并点击选择项（用[]括起来的数字）。
可以使用ESC键或右键单击跳转到下一个选择项，按住右键选择选择项时，会选择并同时跳转到下一个选择项。
其他还有，`Ctrl+V`粘贴剪贴板内容，（与`eramaker.exe`一样）按上下键调出之前的输入等。

可以使用`EraMakerEx`中进行字符串转换的文件直接启动。
但此功能默认是禁用的，如需使用请在帮助设置中勾选`使用_Rename.csv`。

## 宏
Emuera有简单的宏功能。
例如，输入`\e`时与按ESC键或右键单击一样，会跳转到下一个选择项。
输入`\n`时会在那里分割输入，进行下一个输入。
例如，输入`0\e\n1\e\n`时，会输入0并跳转到下一个选择项，输入1并跳转到下一个选择项。
另外，用(～～)*n括起来的输入会重复n次。
`(0\e\n)*3`与`0\e\n0\e\n0\e\n`相同。
另外，可以在宏执行中按ESC键，中止宏的执行。

创建的宏可以与`F1-F12`键关联保存。
按住`Shift`键并按下`F1～F12`键，将当前输入内容保存到`F1～F12`键。
之后，按下`F1～F12键`即可输入保存的宏。
保存的宏存储在`macro.txt`中。
（需要启用配置选项"使用键盘宏"）

另外，按住`Ctrl`键并按下数字`0～9`键，可以切换宏组。
（Emuera启动后默认选择组0）
由于可以在组0的`F1～F12`和组1的`F1～F12`中存储不同的宏，可以记忆更多的宏
组也可以从输入框的右键菜单中更改

也可以直接用文本编辑器编辑`macro.txt`
在`宏键F○:`冒号右侧，写下按下`F○键`时要输入的宏
`G×:宏键F○:`是选择组×时的宏
如果更改`组×:设置为宏组×`冒号右侧的消息，
也可以更改切换到组×时的显示字符串。

## 菜单
使用此功能需要在配置中启用`使用菜单`项目。
默认已启用。

### 文件
#### 重新启动
重新启动Emuera。
如果没有保存，正在运行的游戏信息会丢失，请注意。

#### 保存日志
将过去日志另存为文件。
保存的最大行数与历史日志行数相同。

#### 返回标题画面
返回标题。
如果没有保存，正在运行的游戏信息会丢失，请注意。

#### 重新读取代码
保持游戏信息不变，重新读取.erb文件。
已调用的函数会执行读取前的代码。
调用的函数消失前的代码会留在内存中，连续使用可能导致内存不足。

#### 退出
退出Emuera

### 帮助
#### 设置
进行配置设置。设置详细信息请参考配置。
