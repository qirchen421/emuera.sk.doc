# ショートカットキー
Emueraではいくつかの操作をショートカットキーから行えます。  
EmueraEM+EEで追加された機能についても説明します。  

!!! note "`Ctrl + B`"
	Emueraのウインドウを最小化します。

!!! note "`Ctrl + C`, `Ctrl + Insert`"
	クリップボードダイアログを開きます。  
	この動作は文字が選択されていない場合のみ有効です。  
	何か文字が選択されている場合には単にその文字をコピーします。  

!!! note "`Ctrl + V`, `Shift + Insert`"
	コピーした文字を貼り付けます。  

!!! note "`Ctrl + D`"
	デバッグウインドウを開きます。  
	これはデバッグモードで起動したときのみ有効です。  

!!! note "`Ctrl + R`"
	デバッグウインドウ内の情報を更新します。フォーカスは移りません。
	これはデバッグモードで起動したときのみ有効です。

!!! note "`Ctrl + 0～9`"
	マクログループをグループ0～9に切り替えます。

!!! note "`Shift + F1～F12`"
	現在の文字列をF1～F12にマクロとして割り当てます。

!!! note "`F1～F12`"
	各キーに割り当てられたマクロを呼び出します。

!!! note "`Esc`"
	マクロ実行中に押すことでマクロを中断します。

!!! note "`Ctrl + T`"
	EM+EEで追加された機能です。タイトル画面に戻ります。

!!! note "`Ctrl + R`"
	EM+EEで追加された機能です。再起動します。

!!! note "`Ctrl + O`"
	EM+EEで追加された機能です。ERBを再読み込みします。
