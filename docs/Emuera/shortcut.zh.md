# 快捷键
Emuera可以通过快捷键执行几种操作。
也介绍EmueraEM+EE新增的功能。

!!! note "`Ctrl + B`"
	将Emuera窗口最小化。

!!! note "`Ctrl + C`, `Ctrl + Insert`"
	打开剪贴板对话框。
	此操作仅在未选择任何文字时有效。
	如果选择了文字，则只是复制所选文字。

!!! note "`Ctrl + V`, `Shift + Insert`"
	粘贴复制的文字。

!!! note "`Ctrl + D`"
	打开调试窗口。
	这仅在以调试模式启动时有效。

!!! note "`Ctrl + R`"
	更新调试窗口内的信息。焦点不会移动。
	这仅在以调试模式启动时有效。

!!! note "`Ctrl + 0～9`"
	将宏循环切换到组0～9。

!!! note "`Shift + F1～F12`"
	将当前字符串分配为F1～F12的宏。

!!! note "`F1～F12`"
	调用分配给各键的宏。

!!! note "`Esc`"
	在宏执行过程中按下可中断宏。

!!! note "`Ctrl + T`"
	EM+EE新增的功能。返回标题画面。

!!! note "`Ctrl + R`"
	EM+EE新增的功能。重新启动。

!!! note "`Ctrl + O`"
	EM+EE新增的功能。重新加载ERB。
