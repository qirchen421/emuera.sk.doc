# 用户定义的变量  
通过使用`#DIM`和`#DIMS`可以定义自己喜欢的变量。  
在函数内定义的变量成为仅在该函数内可用的私有变量，  
在[头文件（ERH）](ERH.zh.md)内定义的变量成为在ERB中所有位置都可引用的全局变量。  

## 格式（私有变量的情况）  
在想要定义该变量的函数声明下方记录`#DIM(S) <变量名>, <元素数>{, <元素数>{, <元素数>}}`。  
`<变量名>`与函数名一样，以非数字开头，由符号仅包含`_`的任意字符串组成。  
`<元素数>`是`1～1000000`范围内的任意整数或常量表达式。省略时为`1`。  
根据给予的`<元素数>`数量，定义的变量维度会发生变化。最大为三维，无法定义四维以上的变量。  
通过`#DIM(S)`定义的私有变量可以在单一函数中定义多个。  

通过此方式，使用`<变量名>`指定的变量名在该函数内可用。  
变量可根据`<元素数>`指定的元素数进行赋值，但不会保存。初始值为`0`或空字符串。  
使用`#DIM`定义为整数型变量，使用`#DIMS`定义为字符串型变量。  
通过`#DIM(S)`定义的变量也可指定为其函数的参数。也可以设置初始值。  

	@FIND_CSTR(KEY, VALUE)  
	#FUNCTION  
	#DIM LCOUNT  
	#DIM KEY  
	#DIMS VALUE  
	SIF KEY < 0 || KEY >= VARSIZE("CSTR")  
		RETURNF -1  
	FOR LCOUNT, 0, CHARANUM  
		SIF LCOUNT == MASTER  
			CONTINUE  
		SIF CSTR:LCOUNT:KEY == VALUE  
			RETURNF LCOUNT  
	NEXT  

如上述脚本，通过根据用途命名变量，设置适当的元素数，  
也许可以改善因频繁使用不连续的`LOCAL`导致的可读性下降。  

## 初始值设置  
在声明一维数组变量时，可以定义初始值。  
定义了初始值的数组元素数可以省略，这种情况下初始值的数量自动成为数组的元素数。  
如果不省略元素数，则该数字成为数组的元素数。  
元素数未省略且初始值数量超过元素数时会出错。  

	;因省略元素数，HOGE的元素数为3  
	#DIM HOGE = 1,2,3  

	;因未省略元素数，PUGE的元素数为100  
	#DIM PUGE,100 = 4,5,6  

	;错误（初始值数量超过指定元素数）  
	#DIM HIGE,1 = 7,8,9  

	;字符串变量也可以（用字符串表达式指定）  
	#DIMS SHOGE = "A", "B", "C"  

另外，无法为多维数组定义初始值。  

## 动态变量  
像`#DIM(S) DYNAMIC <变量名>, <元素数>`这样在变量名前加入`DYNAMIC`时，定义的变量会被动态分配。  
具体来说，函数被调用时分配，在函数结束时变量和其中的值都会消失。  
（由于[`RESTART`](../Reference/RESTART.zh.md)指令是"回到函数开头的指令"，即使是动态分配的变量也不会重置）  
函数中调用自身（递归）时，也会为递归的次数分配变量，使递归处理行为稳定。  
但与不加`DYNAMIC`（静态变量）相比，运行速度会变慢。  

## 常量  
在定义一维数组变量时，在变量名前加入`CONST`，可以定义一维数组常量。  
与初始值一样，只能定义一维数组变量。  
常量声明必须有初始值，且中途无法通过赋值更改。  
另外，由于`CONST`的性质，无法与`GLOBAL`、`SAVEDATA`、`REF`、`DYNAMIC`关键字同时使用。  
另外，虽然可以指定数组元素数而不省略，但如果元素数与初始值数量不一致则会出错。  

	;一维常量数组的定义  
	#DIM CONST HOGE = 1,2,3  

	;错误（初始值数量与元素数不一致）  
	#DIM CONST PUGE,100 = 4,5,6  

	;字符串变量也可以（用字符串表达式指定）  
	#DIMS CONST SHOGE = "A", "B", "C"  

## 引用型变量  
在变量名前使用REF关键字，可以定义引用型变量。  
整数型1～3维数组、字符串型1～3维数组分别如下声明。  

	#DIM REF HOGE1DIM,0  
	#DIM REF HOGE2DIM,0,0  
	#DIM REF HOGE3DIM,0,0,0  
	#DIMS REF PUGE1DIM,0  
	#DIMS REF PUGE2DIM,0,0  
	#DIMS REF PUGE3DIM,0,0,0  

如果逗号数量正确，可以省略0。一维数组时也可以省略逗号。  
引用型变量没有实体，操作引用型变量时，会代替操作`REF`指令（截至ver1.815不可用）或通过引用传递接收到的变量。  
关于引用传递的详细信息，请参考函数-参数的引用传递。  

## 格式（全局变量的情况）  
在[头文件（ERH）](ERH.zh.md)内记录`#DIM(S)`时，与在ERB中定义的私有变量不同，  
成为可从ERB中所有位置引用的全局变量。  
与私有变量不同，没有`DYNAMIC`、`STATIC`的区别，也无法定义使用`REF`的引用型变量，但可以像平常一样定义使用`CONST`的常量。  
作为函数中`DIM`没有的功能，可以定义可保存的变量、全局变量、角色变量。  
详情请参考[头文件（ERH）](ERH.zh.md)项。  

## 限制  
### 无法使用与指令相同的名字  
不能定义与以下指令同名的变量。  

	;错误  
	#DIM PRINTFORM  
	#DIM SELECTCASE  
	#DIM CALL  
	#DIM RETURN  
	#DIM GOTO  
	#DIM SQRT  
	#DIM DATAFORM  
	#DIM NOSKIP  
	#DIM FUNC  
	#DIM ENDFUNC  

可以定义与函数名·预处理器同名的变量，但不推荐。  

	;不推荐  
	#DIM EVENTFIRST  
	#DIM COMF32  
	#DIM COMABLE15  
	#DIM SHOW_ABLUP_SELECT  
	#DIM DIM  
	#DIM PRI  
	#DIM ONLY  
	#DIM SKIPSTART  

### 无法从函数外部干预  
与其他`LOCAL@HOGE`的`LOCAL`不同，没有方法可以引用或赋值其他函数的私有变量。  

## `ERD(ERabasic Define)`功能  
EM+EE中新增的功能。可以在ERH中定义的变量上，像CSV变量一样使用`*.csv`文件或`*.ERD`文件设置标识符  
以下，摘自EM+EE摘要  

从`ERH`中定义的变量名开始准照文件加载，可以像现有`CSV`变量一样为数组命名  
`CSV`文件夹内可用的仍为传统的`"变量名.csv"`，`ERB`内可用的为`"变量名.ERD"`文件。格式与`CSV`变量文件相同。即使存在两个以上，只有定义了相同标识符时才会在启动时出错并终止。可以将不同标识符替换为相同整数  
另外，为多维数组变量命名时，可以通过在文件名后跟`@`和数字来对应各维度。从左边的下标开始对应`1`、`2`、`3`  

**ERH**  

  #DIM HOGE, 3  
  #DIM HOGE2D, 3, 3  
  #DIM HOGE3D, 3, 3, 3  

**文件构成**  

    HOGE.ERD  
    HOGE2D@1.ERD  
    HOGE2D@2.ERD  
    HOGE3D@1.ERD  
    HOGE3D@2.ERD  
    HOGE3D@3.ERD
