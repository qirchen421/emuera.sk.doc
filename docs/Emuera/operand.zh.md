# 运算
## 运算符
### 一元运算符
- `~` 按位取反(按位NOT) 一元运算符（优先级最高）
- `!` 逻辑否定(NOT) 一元运算符（优先级最高）

### 二元运算符
- `<<` 左位移。比较和位运算优先级更高，算术运算优先级更低。
- `>>` 右位移。比较和位运算优先级更高，算术运算优先级更低。
- `^` 按位异或(按位XOR) 优先级与&、|相同
- `^^` 非按位异或(非按位XOR) 优先级与&&、||相同
- `!&` 非按位与非(非按位NAND) 优先级与&&、||相同
- `!|` 非按位或非(非按位NOR) 优先级与&&、||相同

### 三元运算符
- `?～#` 普通三元运算符 优先级在=之上，其他运算符之下（判断和结果先合并再处理）

		格式（数值）　：<赋值目标变量> = <条件表达式> ? <为真时的赋值> # <为假时的赋值>
		格式（字符串）：<赋值目标变量> = \@<条件表达式> ? <为真时的赋值> # <为假时的赋值>\@

	处理上等同于

		IF <条件表达式>
			<赋值目标变量> = <为真时的赋值>
		ELSE
			<赋值目标变量> = <为假时的赋值>
		ENDIF

	是一样的。
	另外，数值三元运算符，可以通过放入`()`中，在通常计算中使用，字符串三元运算符可以直接在[`PRINTFORM`](../Reference/PRINT.zh.md)系列指令中使用。
	不过，在`\@～\@`格式的三元运算符中，不能省略`#`。

### 赋值运算符
- `'=` 用于字符串型变量的字符串表达式赋值运算符 [详情请见](expression.md#form_2)

### 自增·自减
- `++` 自增
- `--` 自减
代替赋值语句使用。不能与其他运算符组合。

## 运算的新增
- `==` 字符串之间的比较。不能比较数值和字符串。
- `!=` 字符串之间的比较。
- `<` 字符串之间的比较。比较从开头开始，找到不同字符时立即确定。
- `>` 字符串之间的比较。
- `<=` 字符串之间的比较。
- `>=` 字符串之间的比较。
- `+` 字符串之间的连接。不能对数值和字符串进行加法·连接。
- `*` 字符串与整数的乘法。不能将字符串与字符串相乘。

	**示例**

		STR:0 = % "あ" * 10 %
		PRINTFORML STR:0 = "%STR:0%"
		WAIT

	**结果**

		STR:0 = "ああああああああああ"

## 逻辑运算符的短路评估
短路评估是指例如在`(X && Y)`这样的表达式中，当`X`为`0`时，无论`Y`的值如何，运算结果都明显为`0`，因此不评估`Y`的评估方法。
包括吉里吉里在内的许多语言对逻辑运算符进行短路评估。
通过这种评估方法，可以进行如下写法。

	IF (ASSI >= 0) && (NO:ASSI == 1)
		～～～
	ELSE
		～～～
	ENDIF

当`ASSI`小于等于0时，无论`(NO:ASSI == 1)`的结果如何，整体结果都是`0`，所以不会引用`NO:ASSI`。因此也不会发生错误。
评估顺序是左项优先，右项在后。

	IF (NO:ASSI == 1) && (ASSI >= 0)

这样写的话，会先计算`(NO:ASSI == 1)`，所以在`ASSI < 0`时会出错。
