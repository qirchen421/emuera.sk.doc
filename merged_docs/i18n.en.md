# Internationalization

> EmueraEM+EE has supported internationalization since `Emuera1824+v16+EMv14+EEv24`.

## Display Language

!!! summary ""

    Download the translation file from the table below (right-click → Save link as...), copy the language file to the LANG folder (same location as ERB and CSV folders), and Emuera will automatically detect all `lang/emuera.*.xml` files.
    If not set, the language file is missing, or parts are untranslated, Japanese will be displayed.

    You can select the display language from `Help` → `Settings` → `Display` → `Emuera Display Language`. Alternatively, you can set it in the config file (*.config) using the `Emueraの表示言語` / `Emuera interface language` setting.

    By adding `-genlang` to the Emuera command line (see [Debug Mode](../Emuera/debug.md)), the default language file is automatically generated and saved as `lang/emuera-default-lang.xml`. Translations and distribution of language files are welcome.

!!! example "Example" 

    ``` title="emuera.config"
    Emuera interface language:English
    ```

!!! hint "Hint"

    The `lang` folder is not required if you only use the Japanese version.

## Config

!!! summary ""

    Config items support both Japanese and English, and config files are saved in `UTF-8-BOM`.

    When `Help` → `Settings` → `Environment` → `Output English items in the config file` is selected, config items are output in English. Alternatively, you can set this in the config file (*.config) using the `CONFIGファイルの内容を英語で保存する` / `Output English items in the config file` setting.

    Items in "_Replace.csv" can now also be set in English.
